## 홈(HOME) 화면 — HTML 정합 6가지
- ✏️ **① 요약 카드 번호**: 숫자 텍스트 → 테두리 번호 박스(22×22, radius 5).
- ✏️ **② 목표 카드**: 위쪽 바 제거 → 왼쪽 포인트 세로선(잉크 1.5px). `MAIN GOAL` 자간 넓힘, 제목 세리프 18, 진행바 3px(paper2 위 잉크 채움).
- ✏️ **③ 오늘 할 일**: 둥근 체크박스(radius 4) + 제목 아래 태그 칩(`#긴급`·`#중요`, 긴급=포인트색 테두리) + 우측 `⋯`.
- ✏️ **④ 다음 일정**: 시간 + 포인트색 세로 바 + 제목 + 부제(시간범위·소요분) + 우측 `›`.
- ✏️ **⑤ 오늘의 습관**: 번호 박스(01/02, radius 6) + 제목 + `매일` + 우측 완료(포인트색)/대기 상태.
- ✏️ **⑥ 오늘의 운세**: 테두리 카드(radius 10) + 날짜 박스(MM/dd) + 세리프 제목 + 설명(한글 줄바꿈 처리).

## 오늘(TODAY) 화면 — HTML 정합
- ✏️ **목표 블록**: 가운데 정렬 → 왼쪽 포인트 세로선 카드(왼쪽정렬, TODAY'S GOAL 포인트색 + 세리프 제목 + 설명 + 3px 진행바).
- ✏️ **필터**: 텍스트 탭 → 테두리 칩(전체/미완료/중요/긴급, 선택=잉크 채움).
- ✏️ **할 일 행(공용 SimpleTile)**: 글리프 체크 `○/✓` → 네모 체크박스, `#해시태그` 평문 → 테두리 태그 칩. → 전체(ALL) 화면 할 일 행도 함께 반영됨.

## 전체(ALL) 화면 — HTML 정합
- ✏️ **필터**: 텍스트 탭 → 테두리 칩(전체/오늘/7일/이번 달/기간).
- ℹ️ 할 일 행은 공용 SimpleTile 반영으로 이미 HTML식(네모 체크박스·태그 칩).

## 매트릭스(MATRIX) 화면 — 검토
- ℹ️ 사분면 짧은 라벨 + 상단 기간 바('날짜 없는 일 포함')는 사용자 선택으로 **그대로 유지**(HTML과 의도적 차이). 코드 변경 없음.

## 쏟아내기(DUMP) 화면 — HTML 정합
- ✏️ 입력부: 'FREE NOTE' 이중 라벨·가운데 정렬 제거 → 왼쪽정렬 'BRAIN DUMP' 한 줄 + 왼쪽정렬 입력, 카드 테두리 잉크 + radius 10.
- ✏️ '분류하기' 버튼: 평문 → 테두리 칩(레퍼런스 .classify).
- ℹ️ 분류 워크플로(매트릭스 드롭보드·하단 담기 바·→버킷 표시)는 앱 기능이라 유지(HTML과 의도적 차이).

## 습관(HABIT) 화면 — HTML 정합
- ✏️ **빠른 시작**: 세로 목록(＋제목) → 가로 이모지 칩(레퍼런스 filter-row). § 헤더 + '템플릿' 우측 라벨 추가.
- ℹ️ 습관 메타의 시간대(아침/저녁/밤)는 데이터가 없어 생략(‘매일 · N일 연속’ 유지).

## 설정(SETTINGS) 화면 — HTML 정합
- ✏️ **그룹 카드 묶음**: 각 설정 그룹(글자와 화면/별자리·만세력/집중 설정/구글 캘린더/위젯/백업)을 테두리 카드(radius 10)로 감쌈. 테마 그룹만 카드 없이(스와치 가로 스크롤).
- 🆕 **'다음 할 일 자동 제안' 토글**(집중 설정): 완료 직후 스낵바에 남은 오늘 할 일 한 개를 짚어줌. (설정 필드 `autoSuggestNext` 추가)
- 🆕 **'위젯에서 빠른 입력' 토글**(위젯): 끄면 위젯 탭으로 앱 빠른 담기 입력창을 열지 않음. (설정 필드 `widgetQuickAdd` 추가)
  - ℹ️ Flutter 빠른 담기 경로를 게이트함. 네이티브 인라인 담기(QuickAddActivity)는 별개 위젯이라 이 토글과 무관.

## 일과(ROUTINE) 화면
- ✏️ **day 타임라인**: 색칩 → 플랫 타임라인(시간 · 왼쪽 체크박스+연결선 · 본문 · 우측 소요). 트래커 기록은 작업 불릿 + 시간범위 + 작성/수정시각으로 펼침.
- 🐛 day 타임라인 오른쪽에 세로로 늘어난 체크박스 박스 제거.
- ✏️ **week**: 세리프 큰 날짜 + 한 줄 정보 + 원형 ＋버튼, 오늘 좌측 강조바 + `TODAY` 마커.
- ✏️ **month(달력)**: 오늘 칸 채움 → 잉크 아웃라인. 干支日 항상 표시, 달 모양 숫자 아래로.
- ✏️ **routine 탭**: `AM`/`MD`/`PM` 네모 아이콘 카드 헤더 + 들여쓴 단계 + `+ 단계 추가` (드래그·트리거 기능 유지).
- ✏️ **log**: 1시간 → **30분 단위** 슬롯, 기록행 레일 통일(포인트색 세로선).
- ✏️ day/week/month/routine/log 탭 폰트 축소.
- ✏️ day 타임라인 제목 13→12px (다른 탭 항목 크기와 통일).
- ✏️ day 화면 HTML 정합: 날짜 밑 "통합/섹션 + 일정" 바 제거(바로 타임라인), 날짜에서 "(요일)" 제거.
