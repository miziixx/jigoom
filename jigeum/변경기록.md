## 일과(ROUTINE) 화면
- ✏️ **day 타임라인**: 색칩 → 플랫 타임라인(시간 · 왼쪽 체크박스+연결선 · 본문 · 우측 소요). 트래커 기록은 작업 불릿 + 시간범위 + 작성/수정시각으로 펼침.
- 🐛 day 타임라인 오른쪽에 세로로 늘어난 체크박스 박스 제거.
- ✏️ **week**: 세리프 큰 날짜 + 한 줄 정보 + 원형 ＋버튼, 오늘 좌측 강조바 + `TODAY` 마커.
- ✏️ **month(달력)**: 오늘 칸 채움 → 잉크 아웃라인. 干支日 항상 표시, 달 모양 숫자 아래로.
- ✏️ **routine 탭**: `AM`/`MD`/`PM` 네모 아이콘 카드 헤더 + 들여쓴 단계 + `+ 단계 추가` (드래그·트리거 기능 유지).
- ✏️ **log**: 1시간 → **30분 단위** 슬롯, 기록행 레일 통일(포인트색 세로선).
- ✏️ day/week/month/routine/log 탭 폰트 축소.

## 폰트
- ✏️ 앱 전체 글꼴을 **명조(NanumMyeongjo)** 로 통일.
- 🐛 너무 굵던 문제 → NanumMyeongjo(Regular 400 + Bold 700)로 본문 얇게.
- ✏️ 크기 축소: 마스트헤드 26→22, 제목 19→17, 본문 13→12.
- 🆕 한글이 단어 중간에서 끊기지 않게 줄바꿈 처리(운세 본문 등).
- ℹ️ 설정 > 글자 크기 / 굵기 슬라이더로 직접 조절 가능.

## 하단바
- 🆕 아이콘 추가(집/달력/체크/줄).
- ✏️ 라벨 얇게 + 활성 밑줄.
- 🆕 목표관리 페이지에도 하단바 표시. 담기 = 해당 메뉴 항목 담기(목표관리에선 현재 기간에 목표 추가).

## 목표 관리 (신규)
- 🆕 **목표 관리 페이지** — 사이드바 ☰ → "목표 관리".
  - 기간 탭: 일주일 / 1개월 / 1년 / 직접
  - 목표별 진행률 바 + D-day
  - 상세: 이름·기간·마감일 수정, 하위 할 일 추가/완료, 목표 완료/삭제
  - DB에 `goalHorizon` 컬럼 추가(스키마 v14) → 빌드 시 `build_runner` 필요

## 그 외 화면
- ✏️ **매트릭스**: 틴트 사분면 유지, 모서리 8→12, 제목 산세리프, 사분면 라벨 짧게(긴급·중요 등).
- ✏️ **오늘**: 더보기 `···` → `⋯`.
- ✏️ **시간기록 입력 팝업** → 에디토리얼 시트(`[제목]`+플랫 필드).
- ✏️ **백업 복원 선택 시트** → 에디토리얼 시트로 통일.
- ✏️ 사이드바 메뉴: 다른 메뉴로 이동 시 자동 닫힘.
- ✏️ 앱 좌우 여백(gutter) 18px.
- 🆕 앱 전체를 감싸는 바깥 여백 + 둥근 **테두리 프레임**.
