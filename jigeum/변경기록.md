## 곰곰 리디자인 3단계 — 오늘 홈 시안대로 전면 재구성
- 🆕 `today_view.dart` 홈 순서 재편(시안): 곰곰이 인사 → **상시 캡처 바**(탭→빠른 담기) → **모멘텀**(오늘 완료·연속·진행 중) → **지금 진행 중**(다중 타이머 패널) → **기능 방 6칸** → 오늘의 흐름(기존 날짜·컨텍스트·필터·보드).
- 🆕 모멘텀 — 전부 실데이터: 오늘 완료(doneN) · 연속(`streakProvider` 활동일 연속) · 진행 중(`activeTimersNotifier` 개수, 라이브 갱신).
- 🆕 기능 방 — 색으로 또렷하게(광물색 6종). 실데이터 서브라벨: 쏟아내기 대기 N · 시간 진행 N · 목표 N개 · 습관 오늘 t/h · 루틴 N단계 · 운세(탭). 탭 전환/화면 push 로 원활히 연결. 없는 값은 안내문구(지어내지 않음).
- 3-A(데이터층): `activeTimerNotifier`(단일)→`activeTimersNotifier`(목록)+start/stop, `timer_panel` 다중 표시.

## 곰곰 리디자인 4단계 — 나머지 화면 (흐름 허브 색별 방)
- 🆕 `flow_hub_view.dart` — 기능 방 6칸을 번호(01~06) → **색별 글리프 방**(광물색: 아웃라이너 블루·목표 세이지·습관 플럼·루틴 틸·전체 오커·매트릭스 로즈)으로. 시안 정합.
- ℹ️ 나머지 화면(습관·목표·운세·달력·전체·매트릭스·보관·설정)은 이미 새 곰곰 색으로 렌더됨. 화면별 레이아웃 시안은 아티팩트로 공유(사용자 확인 후 순차 이식).

## 곰곰 리디자인 5단계 — 곰곰이 빈 화면 전 앱 확장
- 🆕 `journal.dart` `emptyStateBear(context, text)` — 곰곰이 + 담백한 안내(진짜 빈 화면 전용). 통계 한 줄용 `emptyNote` 와 구분(습관 통계줄엔 곰 안 붙게).
- ✏️ 전체 할 일·완료 기록·보류함·목표(빈 기간) 빈 화면을 `emptyStateBear` 로 교체 → 앱 전반 빈 화면에 곰곰이 등장.

## 곰곰 리디자인 6단계 — 폰트(시스템 기본)·앱 아이콘(곰곰이)·사람 말투
- 🐛 폰트: `appSerif`가 systemFont와 무관하게 항상 명조(NanumMyeongjo) 강제 → 제목이 계속 명조로 보이던 원인. `appSerif` nullable 로, systemFont 켜면 **제목까지 폰 기본 글꼴**. 기본값 systemFont **true** 로 + 기존 설치 1회 이관(`v4_systemfont_migrated`). 옛 Pretendard 강제 이관 제거. (설정에서 '내장 글꼴' 다시 켤 수 있음.)
- 🆕 앱 아이콘: 새싹 화분 → **아기 갈색곰 곰곰이**(어댑티브 전경 벡터, 앱 마스코트와 동일 색). 배경 꿀크림. 라운드 아이콘도 동일.
- ✏️ 멘트 사람 말투로: 쏟아내기 '판단 끄고 다 뱉기'→'생각나면 적어요', 캡처바 '툭 던져요/곰곰이가 갈라둘게요'→'그냥 적어요/적으면 알아서 정리돼요', 방 서브라벨 전반 자연스럽게, 쏟아내기 빈 화면 문구 정리.

## 곰곰 리디자인 7단계 — 나머지 화면 정합(설정 곰곰이) + 감사
- ✏️ `settings_screen.dart` 헤더 우측에 곰곰이(Masthead actions) — 시안대로.
- ℹ️ 매트릭스는 이미 색 사분면(긴급·중요=적 DO FIRST)로 시안 취지 충족 → 미변경(빨강이 더 맞음).
- ℹ️ 나머지 화면(습관·목표·운세·달력·전체·보관)은 이전 세션 HTML 리디자인 + 새 곰곰 색 + 시스템 폰트 + 빈화면 곰곰이로 이미 시안 구조 충족. 개별 재작성보다 실기기 확인 후 구체 지적 반영이 안전.

## 곰곰 리디자인 8단계 — 시스템 폰트 굵기 정합 + 타이머 아이콘
- 🐛 두꺼움: 앱 굵기가 명조 기준(제목 w700 등)이라 시스템 산세리프에선 뚱뚱. `AppText.serif`가 raw weight만 써 전역 굵기를 안 따르던 것도 원인.
- ✏️ `theme.dart` — `serif`가 전역 굵기(appWeightDelta) 반영. **systemFont면 전체 −1 단계 가늘게**(산세리프 보정). 본문/제목/라벨 일괄 적용.
- ✏️ `today_view` — 섹션 헤더 w700→w600, 방 이름 w600→w500(전역 −1과 합쳐 자연스러운 굵기).
- ✏️ `timer_panel` — '지금 진행 중' 시작 버튼 이모지 ▶ → 깔끔한 벡터 재생 아이콘(잉크 채움 원 + 흰 play).
- ℹ️ 폰트: systemFont(기본)로 이미 폰 기본 글꼴 사용. 앱은 시스템 '기본' 글꼴만 따를 수 있고 개별 설치 커스텀 폰트까지는 불가(안드로이드 한계).

## 곰곰 리디자인 9단계 — 글꼴 선택기 실제 작동
- 🐛 `theme.dart` build()가 `fontKey`를 받기만 하고 무시(Pretendard 고정) → 설정의 글꼴 선택기가 UI만 있고 적용 안 됨.
- ✏️ 배선: 휴대폰 글꼴 사용 끄면 사용자가 고른 번들 글꼴(`familyForFontKey(fontKey)`)을 본문·제목에 모두 적용. (프리텐다드·나눔고딕·나눔명조·고운돋움)
- ✏️ `settings_controller.setFontKey` — 글꼴을 고르면 '휴대폰 글꼴 사용'을 자동으로 끄고 그 글꼴 적용(직관적 동작).
- ℹ️ 사용자의 임의 커스텀 시스템 폰트(궁서·굴림 등)를 앱이 자동으로 읽는 건 안드로이드/Flutter 한계로 불가 — 대신 번들 글꼴 선택 + 휴대폰 기본 글꼴(최선) 제공.

## 곰곰 위젯 1단계 — 완전 투명 캘린더 (갤럭시 스타일)
- ℹ️ 투명도: 이미 `KEY_OPACITY`(0~100) 배경 알파로 조절됨 — **0%면 완전 투명(패널 없이 내용만)**. 설정 슬라이더 0까지 지원.
- ✏️ `CalendarWidgetProvider` — 갤럭시처럼 **주말 색**: 일=빨강(#C0645A)·토=파랑(#5F7DA0). 오늘=테마 포인트(mark), 이번달 밖=흐림.
- ✏️ `calendar_widget.xml` — 요일 헤더 '토' 파랑.
- ✏️ 설정 라벨 '위젯 투명도'(값은 불투명도라 오해) → **'위젯 배경 진하기'** + '0% 완전 투명 ~ 100% 꽉 참' 안내.
- ℹ️ 위젯은 앱 테마 6토큰을 push 받아 곰곰 색 따라감. (일정 색 바 pill 은 다음 단계 — 날짜별 일정 데이터 파이프라인 필요.)

## 곰곰 위젯 2단계 — 생성 시 설정창(위젯별 투명도)
- 🆕 캘린더 위젯에 **구성 액티비티**(`CalendarConfigActivity`, 네이티브) — 홈에 얹으면 먼저 설정창이 떠서 **배경 진하기(투명도)** 슬라이더로 정하고 '확인'하면 그 값으로 생성. (앱 안 설정이 아니라 위젯별·생성 시점.)
- 🆕 `res/layout/calendar_config.xml` — 딤 + 크림 카드 + 슬라이더(0 완전투명 ~ 100 꽉참) + 취소/확인. QuickAdd 팝업 톤.
- ✏️ `WidgetPrefs` — 위젯별 투명도 저장/조회(`opacity_<id>`, 없으면 전역 fallback). `CalendarWidgetProvider`가 위젯별 알파 사용.
- ✏️ `calendar_widget_info.xml` `android:configure=...` + `ci_patch_android.py` 매니페스트에 액티비티 등록.
- ℹ️ 기존 배치 위젯은 전역 설정 fallback 유지. 새 위젯은 생성 시 설정창.

## 곰곰 위젯 3단계 — 설정창 재디자인(바텀시트) + 글자·테마 (모든 위젯 공통)
- ✏️ 위젯 생성 설정창을 **예쁜 바텀시트**로 재디자인(위쪽 둥근 크림 + 핸들 + 딤). 상단 붙던 못난 카드 → 하단 시트.
- 🆕 컨트롤 3종: **배경 진하기**(0 완전투명~100) · **글자 크기**(작게/보통/크게 칩) · **테마**(앱 따라가기 + 곰곰 6테마 색 스와치).
- ✏️ **모든 위젯 공통 적용**: 확인 시 전역 저장(`KEY_OPACITY`·`KEY_W_FONTSCALE`·`KEY_W_THEME`) + `updateAllWidgets`. `WidgetPrefs.palette` 가 위젯 테마를 반영, `fontScale` 로 글자 배율.
- ✏️ `CalendarWidgetProvider` — 글자 배율(title·cells·foot `setTextViewTextSize`) 적용, 투명도 전역화.
- ℹ️ 글자 배율은 캘린더 위젯부터 적용(다른 위젯은 순차). 테마·투명도는 전 위젯 즉시 반영.
