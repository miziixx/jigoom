## 홈(HOME) 화면 — HTML 정합 6가지
- ✏️ **① 요약 카드 번호**: 숫자 텍스트 → 테두리 번호 박스(22×22, radius 5).
- ✏️ **② 목표 카드**: 위쪽 바 제거 → 왼쪽 포인트 세로선(잉크 1.5px). `MAIN GOAL` 자간 넓힘, 제목 세리프 18, 진행바 3px(paper2 위 잉크 채움).
- ✏️ **③ 오늘 할 일**: 둥근 체크박스(radius 4) + 제목 아래 태그 칩(`#긴급`·`#중요`, 긴급=포인트색 테두리) + 우측 `⋯`.
- ✏️ **④ 다음 일정**: 시간 + 포인트색 세로 바 + 제목 + 부제(시간범위·소요분) + 우측 `›`.
- ✏️ **⑤ 오늘의 습관**: 번호 박스(01/02, radius 6) + 제목 + `매일` + 우측 완료(포인트색)/대기 상태.
- ✏️ **⑥ 오늘의 운세**: 테두리 카드(radius 10) + 날짜 박스(MM/dd) + 세리프 제목 + 설명(한글 줄바꿈 처리).

## 시간 기록 입력 — 컴팩트 '계속 담기'로 개편 (요청)

  - **컴팩트 버튼**: 취소/저장(큰 EdButton) → 닫기/담기(높이 38·radius 2).
  - 적용: 지금 기록(로그 담기)·빈 슬롯 탭·기존 기록 탭·위젯 진입·달력 기록 담기 전부.
