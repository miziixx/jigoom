# 노션 실시간 자동 공유 — 설정 가이드

앱의 기록(할 일·목표·메모·일정·습관·타임트래커)을 **노션 데이터베이스로 실시간
자동 공유**한다. OAuth 없이 노션 **Internal Integration 토큰** 한 개만 붙여넣으면 된다.

> ⚠️ **웹(PWA)에서는 동작하지 않는다.** 노션 API 가 브라우저 CORS 를 막기 때문에
> **안드로이드 앱**에서만 쓸 수 있다(구글 캘린더 연동과 같은 제약).

---

## 1. 노션에서 Integration 만들기

1. https://www.notion.so/my-integrations → **New integration** 생성.
2. 유형은 **Internal**. 만들면 **Internal Integration Secret**(`secret_…` 혹은
   `ntn_…`)이 나온다 — 이 토큰을 복사해 둔다.
3. 능력(capabilities)은 **Insert content / Update content / Read content** 를 켠다.

## 2. 공유할 부모 페이지 준비

1. 노션에서 기록을 모아둘 **페이지 하나**를 만든다(예: "지금 기록").
2. 그 페이지 우측 상단 **⋯ → Connections → (내 integration) 연결**.
   - 이렇게 공유해야 앱이 이 페이지 아래에 데이터베이스를 만들 수 있다.
3. 페이지의 **링크 복사**(Copy link) — URL 을 그대로 붙여넣으면 된다.

## 3. 앱에서 연결

**설정 → Notion** 섹션에서:
1. **통합 토큰**에 1단계에서 복사한 `secret_…` 를 붙여넣기.
2. **부모 페이지 주소**에 2단계에서 복사한 링크를 붙여넣기.
3. **노션 연결 켜기** → 토큰이 검증되면 연결 완료.

연결되면:
- **실시간 자동 공유** 토글(기본 켜짐): 기록이 바뀔 때마다 자동으로 노션에 올린다.
- **공유할 기록 종류**: 할 일/일정/습관/타임트래커 중 원하는 것만 켠다
  (기본: 할 일·일정 켜짐).
- **지금 동기화**: 수동으로 한 번 밀어 올린다.

## 4. 동작 방식

- 유형마다 부모 페이지 아래 **데이터베이스가 자동 생성**된다
  (예: `지금 · 할 일·목표·메모`).
- 각 행에는 원본 레코드 id 가 **`JigeumId`** 속성으로 들어가고, 이 값을 키로
  **upsert** 한다 — 같은 기록을 고쳐도 새 행이 생기지 않고 그 행이 갱신된다.
- 자동 공유는 **변경분만**(마지막 공유 이후 바뀐 것) 올리므로 노션 API 한도에 안전하다.
- 트리거: 기록 변경(0.5초 디바운스) · 앱 재개(resume) · 콜드 스타트 · "지금 동기화".

## 5. 주의

- 공유는 **앱 → 노션 단방향**이다(노션에서 고친 내용은 앱으로 돌아오지 않는다).
- **연동 끄기**는 앱에 저장된 토큰·설정만 지운다 — 노션에 이미 만들어진
  데이터베이스·행은 그대로 남는다(원하면 노션에서 직접 정리).
