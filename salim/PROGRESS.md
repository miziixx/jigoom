# 살림 관리 — 개발 진행 (PROGRESS)

## 작업 규칙

- 한 번에 **"하나의 작은 작업"**만 한다.
- 각 작업이 끝나면 아래 해당 항목을 `[x]`로 바꾸고, `RECORD.md`에 기록을 남긴 뒤 멈춘다.
- 사용자가 **"다음"** 또는 다음 지시를 주면 이어서 한다.

> 상태 표기: `[ ]` 예정 · `[x]` 완료
