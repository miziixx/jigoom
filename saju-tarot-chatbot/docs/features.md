# 사주타로 챗봇 기능 정리

마지막 업데이트: 2026-07-05

이 문서는 `saju-tarot-chatbot` 앱에 들어간 기능을 사용자 관점과 구현 관점으로 정리한 목록이다.

## 앱 정체성

`인사이트 오라클`은 생년월일과 질문을 바탕으로 사주, 타로, 궁합, 이름 감정/추천을 제공하는 리딩 웹앱이다.

핵심 방향은 다음과 같다.

- 계산은 코드가 하고, 해석 문장은 AI가 작성한다.
- 생년월일 원본은 AI에 보내지 않고, 브라우저에서 계산된 사주 결과와 질문만 해석 생성에 사용한다.
- 본문은 쉬운 생활 언어로 먼저 보여주고, 전문 용어와 계산 근거는 접힘 영역에 보관한다.
- 단정적 예언보다 경향, 조건, 선택 기준, 현실 행동을 제공한다.
- 사용자가 너무 많은 정보를 고르지 않아도 질문 문장을 보고 분야와 의도를 자동으로 파악한다.
- 결과가 "나만을 위한 리포트"처럼 느껴지도록 개인 요약, 반복 패턴, 생활 처방을 제공한다.

## 공통 사용자 경험

### 간단 입력

- 기본 사용자는 많은 옵션을 고르지 않아도 된다.
- 사주 입력은 생년월일, 출생 시간, 성별, 질문 중심으로 단순화했다.
- 출생지 보정, 원국 저장, 분야 선택, 말투, 해석 깊이, 최근 상황 입력은 접힘 영역에 둔다.
- 출생지는 필수는 아니지만, 알면 시주 경계 판단이 더 정밀해진다고 안내한다.

### 질문 의도 자동 파악

사용자가 질문을 쓰면 앱이 내부적으로 질문 분야를 추정한다.

- 연애·관계
- 일·돈·진로
- 건강·컨디션
- 마음상태
- 선택·시기
- 전반

사용자가 직접 분야를 고르면 직접 선택값을 우선하고, 고르지 않으면 질문 문장으로 추정한다.

### 말투 선택

말투 선택지는 복잡하지 않게 줄였다.

- 기본
- 현실적으로
- 부드럽게
- 행동 중심

### 결과 구조

결과는 빠른 요약을 먼저 보여주고, AI 상세 리딩은 아래에 이어서 보여준다.

기본 흐름:

1. 한 줄 결론
2. 내 사용 설명서
3. 키워드와 요약 카드
4. 사주 원국 요약
5. 질문 중심 핵심 답변
6. 전체 총평
7. 분야별 요약
8. 목차
9. 계산 근거 자세히 보기
10. 상세 풀이 섹션
11. 마지막 정리
12. 생활 처방과 실행 행동

## 사주 리딩

### 사주 계산

코드로 계산하는 항목:

- 양력/음력 생년월일
- 음력 윤달
- 출생 시간 모름 처리
- 23:00 전후 자시 기준
- 출생지 경도 보정
- 한국 서머타임 보정
- 표준시 변경 기간 보정
- 연주, 월주, 일주, 시주
- 오행 분포
- 음양 분포
- 천간 십성
- 지지 십성
- 지장간
- 합충형파해
- 신강/신약
- 용신/희신/기신 후보
- 12운성
- 공망
- 조후 노트
- 격국
- 신살
- 60갑자 일주 성향
- 대운
- 세운
- 월운
- 오늘 일진

### 사주 결과 화면

사주 결과는 읽기 쉽게 상단 요약과 상세 근거를 분리한다.

- 계산 기반 즉시 요약
- 내 사용 설명서
- 강점
- 주의점
- 잘 맞는 일 방향
- 지금 필요한 행동
- 기질 스펙트럼
- 인생 영역 막대
- 반복 패턴 지도
- 월별 실행 캘린더
- 사주 원국 표
- 오행 그래프
- 음양 그래프
- 신살 목록
- 대운/세운/월운 흐름
- 전문가 근거 보기

### 내 사용 설명서

결과 상단에서 "이 사람만의 차이"를 먼저 보여준다.

- 내가 어떤 사람처럼 움직이는지
- 반복 패턴
- 무너지는 지점
- 살아나는 방식
- 오늘 바로 시작할 맞춤 행동

이 항목은 사주 구조, 강한 기운, 약한 기운, 신강/신약, 생활 처방을 조합해 만든다.

### 생활 처방

오행 분포와 보완 기운을 생활 행동으로 번역한다.

제공 항목:

- 고유 색
- 고유 숫자
- 맞는 방향
- 잘 맞는 장소
- 자연 키워드
- 운동
- 건강 체크 포인트
- 일하는 방식
- 회복 루틴
- 재미 미션
- 바로 실행 3개

예시:

- 바다나 강 배경화면으로 바꾸기
- 책상 위에 물컵 두기
- 작은 식물 두기
- 오늘 안 쓰는 앱 3개 지우기
- 이번 주 돈 나갈 곳 3개 메모하기

생활 처방은 절대적인 행운 예언이 아니라, 계산된 보완 흐름을 일상에서 써먹기 쉽게 바꾼 가이드다.

### 날짜 기반 보완법 변화

오늘 운세나 흐름을 볼 때 같은 보완 기운이라도 매번 똑같은 조언만 나오지 않도록 했다.

- 계산된 보완 기운은 고정한다.
- 보여주는 실행법은 날짜, 오늘 일진, 원국 정보를 seed로 섞는다.
- 같은 날에는 같은 조언이 유지된다.
- 날짜가 바뀌면 오늘 행동, 재미 미션, 회복 루틴 조합이 달라질 수 있다.

## 오늘 운세

`오늘 운세`는 사주 원국과 오늘 일진을 바탕으로 짧고 실용적인 운세를 보여준다.

기능:

- 오늘 점수
- 오늘 총운
- 분야별 운세
- 시간대별 흐름
- 추천 행동
- 피할 행동
- 오늘의 행운 아이템
- 오늘의 카드

오늘 운세는 종합 생애 리딩처럼 길게 쓰지 않고, 오늘과 이번 주 중심으로 짧고 실용적으로 제공한다.

## 흐름 캘린더

`흐름 캘린더`는 월간/연간 흐름을 보는 메뉴다.

기능:

- 올해 1월부터 12월까지 월별 흐름
- 각 월의 키워드
- 좋아지는 기회
- 조심할 점
- 한 줄 조언
- 대운 흐름
- 세운 흐름
- 월운 흐름
- 월별 실행 캘린더

흐름 리딩은 성격, 직업, 연애 같은 생애 전체 풀이를 반복하지 않고 시기 흐름에 집중한다.

## 타로 리딩

### 타로 입력

기본 화면에서는 질문만 입력해도 된다.

접힘 영역에서 직접 고를 수 있는 것:

- 스프레드
- 셔플 방식
- 자동 뽑기/직접 고르기
- 말투와 추가 상황

### 타로 스프레드

지원 스프레드:

- 1장
- 3장 과거·현재·미래
- 3장 상황·장애물·조언
- 5장 흐름
- 5장 선택지 A/B 비교
- 5장 한 달 흐름
- 5장 관계 리딩
- 10장 켈틱 크로스

### 셔플 방식

셔플 방식은 결과 근거 문장에 반영된다.

- 기본 셔플
- 리플 셔플
- 손끝으로 고르기
- 직접 고르기

### 타로 상징 해석

카드별로 다음 근거를 사용한다.

- 상징 원형
- 상징 키워드
- 그림 단서
- 숫자/단계 의미
- 슈트 의미
- 관계 적용
- 정방향/역방향 의미
- 자리 의미

### 타로 조합 진단

카드 조합을 숫자처럼만 보지 않고 흐름으로 엮는다.

- 정방향/역방향 비율
- 메이저 카드 비율
- 반복 슈트
- 시작 카드에서 마지막 카드로 이어지는 흐름
- 원소 조합 규칙
- 카드 간 강화/충돌/전환

### 순수 타로 응답 범위

타로만 보는 경우 사주 종합 리딩을 억지로 붙이지 않는다.

섹션:

1. 첫 점괘
2. 질문 중심 핵심
3. 카드가 그리는 흐름
4. 지금 해야 할 것과 피해야 할 것
5. 마지막 점괘

## 오늘의 카드

날짜 기준으로 오늘의 카드를 뽑아 보여준다.

기능:

- 오늘의 카드
- 카드명
- 정방향/역방향
- 슈트
- 오늘의 키워드
- 분위기
- 현실 조언

키워드는 "Queen 단계" 같은 어색한 표현이 아니라, 카드의 랭크와 슈트를 쉬운 말로 번역해 보여준다.

## 사주 + 타로 통합

통합 리딩은 사주와 타로의 역할을 분리한다.

- 사주: 타고난 구조, 반복 패턴, 장기 흐름, 올해 흐름
- 타로: 지금 질문의 가까운 심리, 단기 분위기, 선택 신호

기능:

- 사주 입력
- 질문 입력
- 기본 3장 타로
- 스프레드/셔플 선택은 접힘 영역
- 사주 요약
- 타로 카드 요약
- 질문 중심 핵심
- 사주로 보는 장기 흐름
- 타로로 보는 현재 흐름
- 통합 판단

통합 결과는 질문이 연애, 돈, 일, 관계, 건강, 선택, 전반 중 무엇이든 사주와 타로를 둘 다 사용해 해석한다.

## 궁합

### 궁합 입력

나와 상대를 명확히 구분한다.

입력 항목:

- 나의 생년월일시
- 상대의 생년월일시
- 분 입력
- 시간 모름
- 23:00 전후 기준
- 출생지 보정
- 성별
- 관계 유형
- 궁금한 점

관계 유형은 너무 많지 않게 줄였다.

- 연인·배우자
- 가족
- 업무·협업
- 친구·지인

### 궁합 계산

룰 기반으로 계산하는 항목:

- 두 사람의 일간 관계
- 일지 중심 관계 자리
- 오행 보완
- 합충형파해
- 감정/표현/책임/생활 리듬
- 시기 흐름
- 관계 목적별 점수
- 세부 흐름 점수

### 궁합 결과

결과 항목:

- 관계 종합
- 두 사람 원국 요약
- 나/상대 구분 카드
- 관계 핵심 카드
- 일지 중심 관계 자리
- 서로에게 어떤 존재로 느껴지는지
- 관계 목적별 궁합
- 세부 흐름
- 관계 보완 리포트
- 조심할 반복 패턴
- 오래 가는 운영법
- 질문 의도 먼저 보기
- 전문가 근거 보기

### 관계 보완 리포트

점수가 낮거나 부딪힘 신호가 많을수록 보완 중심으로 더 자세히 보여준다.

포함 항목:

- 관계 보완 헤드라인
- 왜 이런 흐름이 생기는지
- 갈등이 커지는 순서
- 회복법
- 나의 조율법
- 상대의 조율법
- 둘이 같이 할 일
- 실제 대화 문장 예시
- 하지 않는 편이 좋은 반응
- 7일 조율 플랜

### 궁합 질문 답변

궁합에서도 질문을 넣으면 별도 카드로 먼저 답한다.

- 질문 의도
- 현실 답변
- 확인해야 할 신호
- 바로 할 행동

## 이름 감정·추천

### 이름 감정

사용자가 후보 이름을 넣으면 사주와 이름의 흐름을 평가한다.

계산 항목:

- 발음오행
- 소리의 흐름
- 사주 보완 기운과의 적합도
- 선택 입력한 한자 획수
- 수리성명학 참고 점수

결과:

- 종합 판정
- 이름 소리 흐름
- 사주 보완 적합도
- 획수 수리
- 보완하면 더 좋아지는 점
- AI 해석 리포트

### 이름 추천

사주에서 보완하면 좋은 기운과 어울리는 소리를 기준으로 이름 후보를 추천한다.

지원 목적:

- 아기 이름
- 개명 이름
- 예명·활동명
- 상호명·브랜드명

입력:

- 성
- 원하는 이미지
- 피하고 싶은 발음/느낌
- 목적 메모
- 생년월일시

결과:

- 추천 방향
- 후보 이름
- 한자 뜻 제안
- 소리 근거
- 이미지 설명
- 후보별 점수표
- 후보 비교
- AI 종합평
- PDF 저장
- 마크다운 저장
- 이미지 ZIP 저장

주의:

- 인명용 한자 DB가 완전히 붙기 전에는 한자 뜻과 자원오행을 확정 판정처럼 말하지 않는다.
- 아기 이름·개명은 참고 자료와 선택 기준 중심으로 안내한다.
- 이름을 좋다/나쁘다로 단정하지 않는다.

## 후속 질문 챗봇

리딩 결과 아래에서 후속 질문을 할 수 있다.

기능:

- 리딩당 최대 5개 질문
- 질문이 짧으면 먼저 짧게 답변
- "자세히", "깊게"라고 쓰면 더 깊은 답변
- 기존 리딩 맥락을 이어서 답변
- 질문과 답변은 저장 파일에 포함 가능

추천 질문은 버튼으로 누르게 하지 않고, 예시 문장처럼만 보여준다. 상황에 맞지 않는 버튼을 누르는 문제를 줄이기 위해서다.

## 저장과 내보내기

### 기록

- 리딩 결과를 기록에 저장할 수 있다.
- 원국 저장 체크를 켜면 사주/오늘/흐름 리딩이 기록에도 남는다.
- 기록은 서버가 아니라 브라우저 localStorage에 저장된다.
- 기록에서 즐겨찾기를 할 수 있다.
- 즐겨찾기만 필터링할 수 있다.
- 기록에서 리딩을 다시 열 수 있다.

### PDF 저장

- 결과 화면을 PDF로 저장할 수 있다.
- 접힌 섹션을 모두 펼친 뒤 인쇄 다이얼로그를 실행한다.
- 인쇄 전용 밝은 테마를 사용한다.

### 마크다운 저장

- 리딩 결과를 마크다운 파일로 저장할 수 있다.
- 사주 원국, 생활 처방, 반복 패턴, 질문/답변이 포함된다.

### 이미지 저장

- 핵심 요약과 사주/타로 정보를 이미지 카드로 저장할 수 있다.
- 여러 장 이미지는 ZIP으로 저장할 수 있다.

## 피드백과 개인화

### 피드백

리딩 후 피드백을 남길 수 있다.

- 잘 맞음
- 일부 맞음
- 잘 모르겠음
- 안 맞음

태그:

- 너무 추상적
- 더 구체적이면 좋음
- 조언이 좋음
- 설명이 어려움

피드백은 브라우저에 저장된다.

### 피드백 반영

사용자가 동의하면 지난 피드백에서 스타일 힌트를 만들어 다음 리딩에 반영한다.

예:

- 더 구체적으로
- 어려운 표현 줄이기
- 행동 조언 중심

### 기록 인사이트

기록 페이지에서 볼 수 있는 것:

- 평가 분포
- 자주 남긴 피드백 태그
- 반복 키워드
- 후속 질문 개수

## 리딩 비교

기록에서 리딩 2개를 선택해 비교할 수 있다.

기능:

- 두 리딩 나란히 보기
- 공통 흐름
- 달라진 점
- 반복 주제
- 지금 취할 행동
- AI 비교 분석

프리미엄 게이트 구조가 있으며, 현재는 결제 연동 전 스텁 형태다.

## 개인정보와 안전 안내

### 개인정보 처리

- 생년월일 원본은 브라우저에서 계산에 사용한다.
- AI 해석 요청에는 생년월일 원본 대신 계산된 사주 정보와 질문이 전송된다.
- 저장 기능은 서버 저장이 아니라 브라우저 localStorage 저장이다.
- 개인정보 안내 페이지에서 처리 방식을 설명한다.

### 안전 문구

리딩 결과는 다음 영역에서 단정하지 않는다.

- 의학
- 법률
- 투자
- 결혼
- 이별
- 퇴사
- 이직

대신 선택 기준, 확인해야 할 현실 신호, 행동 가이드를 제공한다.
