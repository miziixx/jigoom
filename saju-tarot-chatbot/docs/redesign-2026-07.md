## 1. 정체성

> **막연한 운세가 아니라, 계산된 근거로 내 고민에 답하는 사주·타로 상담소.**

- 겉모습: 포스텔러형 카드 진열 + 헬로우봇형 말풍선 전달
- 속: 진짜 만세력 계산(4대 고전·용신·조후) + 검증 게이트 — 경쟁 6사 중 아무도 없는 조합
- 포지셔닝 규칙: **"AI 사주"라고 팔지 않는다.** "계산 기반·근거 기반"으로 말한다(명사도 교훈 —
  AI는 이제 싸구려 신호. 우리는 실제로 계산이 본체이므로 거짓말도 아니다).
- 디자인: **현재 앱의 한지 팔레트 유지**(크림 배경·갈색 글자·금갈색 포인트·오행 색). 그라데이션 금지(운영자 확정).
- 타겟: 특정하지 않음. 카드 진열이 스스로 타겟팅한다(연애 고민 젊은 층 → 연애운 카드,
  가족 사주 → 평생사주 카드 + 사이드바 프로필 전환).

## 3. 아키텍처 — 하이브리드 4단 파이프라인

> **계산 엔진 → 해석 룰/판단 엔진 → 빠른 기본 리딩(룰 렌더) → 필요한 부분만 AI 심화·문장화**

| 층 | 담당 | 상태 |
|---|---|---|
| 1. 계산 | `saju.ts`·`eventEngine` (만세력·용신·조후·합충·신살) | ✅ 완성 |
| 2. 판단 룰 | JudgmentPack·psychLayer·monthFlowNarrative·관계 보완 리포트·생활 처방 | ✅ 거의 완성 (현재는 검증 게이트/앵커로만 쓰임) |
| 3. 기본 리딩 (룰 렌더러) | InstantSummary·내 사용 설명서 등 부품만 존재 | 🔨 **신규 조립** — JudgmentPack을 한국어 문장으로 직접 렌더 |
| 4. AI 심화 | 현재 AI가 전체(6,200~8,000자)를 씀 | 🔨 **역할 축소** — 토픽/질문 부분만 1,000~2,500자 |

핵심 전환: **AI를 '책 전체의 집필자'에서 '선택 부분의 심화 작가'로 축소.**
- 퀄리티 보장: 내용의 정확성(판단)은 2층 룰 담당(골든 테스트 618+로 검증된 층). AI는 문장화만
  하므로 분량 축소·모델 하향에도 품질 유지. JudgmentPack 검증이 모순을 거름.
- "AI 없이 템플릿만" 경로는 기각 — 근거: 월별 흐름 고정 라벨 4개가 "뭉뚱그려 보인다"는 피드백으로
  monthFlowNarrative를 만든 자체 이력 + 템플릿 물량전은 포스텔러가 이긴 판.
  기준선: **판단의 템플릿 렌더 = OK, 판단 없는 범용 문장 = NO.**
- 3층(룰, API 비용 0) = 무료 / 4층(AI 심화) = 유료 → **속도 구조가 곧 수익 구조.**

## 4. 상품 구조 — 바벨 (진열은 넓게, 유료 간판은 2개)

원칙: 계산 엔진 1개 + 리딩 파이프라인 1개. 상품은 "토픽 섹션 템플릿"으로만 정의
(selfDeep/personDeep에서 검증한 `analysisMode` 방식의 일반화 — 새 ReadingType 남발 금지).

### 무료·저가 존 (넓게 — 유입 담당)

| 상품 | 생성 방식 | 비고 |
|---|---|---|
| 오늘 운세 + 오늘의 타로 | 룰 (+Haiku 한 줄 선택) | 재방문 훅 |
| 이달의 운 | 룰 | 흐름 캘린더에서 추출 |
| **택일 (신규)** | 룰 (일진·월운·합충 엔진) | 이사·계약·고백·시험 좋은 날 3개 + 피할 날. 점신 '지정일 운세'가 수요 방증. 공유 잘 되는 훅 |
| 기본 리딩 ("내 기본 구조") | 룰 렌더러 (P0) | 모든 리딩 상단 공통 → 토픽 여러 개 사도 중복감 없음 |
| 토픽 리딩 (연애/재물/직업/건강/올해) | Haiku 심화 | 소형 유료(2,900~4,900) 또는 첫 1회 무료 티저 |

### 유료 간판 (좁게 — 퀄리티 몰빵, 명사도의 '상품 2개 집중' 교훈)

| 상품 | 기반 | 베타 가격 |
|---|---|---:|
| 📜 **평생사주 리포트** | 전체 사주 리딩 + PDF | 9,900원 |
| 🕵️ **상대 해부** | personDeep 16항목 | 9,900원 |

상대 해부 선정 근거: 헬로우봇 유료 1위('그 사람의 속마음')와 같은 카테고리 — 지불 의사 검증 완료.
나 해부(selfDeep)·고민상담·정밀 궁합은 상품으로 유지하되 간판 승격은 데이터 보고 결정.

### 정리되는 것
- 작명: 홈에서 제외, 사이드바 링크로. / 타로 단독: 오늘의 타로 + 고민상담에 흡수.
- 기록/비교: "내 기록"으로 통합. / 텔레그램 봇: 범위 밖(운영자 취미).

## 5. 화면 설계

### 홈 — 카드 진열대 (시안 ①)
- 첫인사: **일진·절기 계산으로 매일 자동 생성** ("7월 9일 · 丙午일 · 소서 무렵 / 더위가 여무는 날…").
  접수처식 멘트("무슨 일로 왔어요?") 금지 — 운영자 반려. 첫 문장부터 "진짜 계산" 증명.
- 오늘 카드(무료) → 토픽 그리드(오행 단색) → 유료 간판 2개(큰 카드) → 관계 → 하단 작은 링크.
- 모든 카드에 소요시간 배지(무료·즉시 / 약 30초 / 정성 리포트).
- ⚠️ 시안의 모든 멘트는 배치 확인용 — 실제 카피는 별도 작업(구현 시 운영자 톤 확인 단계 필수).

### 사이드바 (신규, 운영자 요청)
햄버거 메뉴. 홈은 상품 진열만 남기고 보조 기능을 전부 수납:
- **저장된 사주 전환** — 나/가족 프로필 스위처 (운영자 사용 패턴: 가족 사주 자주 봄. 기존 원국 저장 기능 활용)
- 내 기록 (기록+비교 통합) / 이름 감정·작명 / 설정 (테마 등) / 개인정보 처리방침
- 신뢰 코너: "어떻게 계산하나요?" — 분 단위 보정·4대 고전·근거 공개 소개 페이지 (coldcow 교훈, §7과 연결)

### 결과 — 말풍선 점진 공개 (시안 ②)
룰 카드(내 기본 구조, 0초) → AI 말풍선 도착 순 표시 → 타이핑 인디케이터 → 후속 질문 칩(5회 제한 유지).

### 평생사주 본문 (시안 ④) + 진행 화면 (시안 ③)
기본 리딩(룰, 즉시·무료) 위 / AI 12섹션이 도착 순으로 아래 채움 / 스티키 목차 진행 표시.
"멈춘 3분"을 "읽으면서 도착"으로 재해석.

## 6. 파트별 모델 배정 ★

기준 단가 (1M 토큰당, 2026-07 현재): **Haiku 4.5** $1/$5 · **Sonnet 5** $3/$15(8월까지 한시 $2/$10)
· Opus 4.8 $5/$25 · Fable 5 $10/$50.

**Opus·Fable은 쓰지 않는다.** 판단(정확성)은 룰 엔진 담당이고 AI 역할은 문장화·심화라서
Sonnet이 품질 상한선으로 충분. Fable은 Sonnet의 3배+ 가격에 이 워크로드에선 이득이 없음.

| 파트 | 모델 | 1회 예상 비용* | 근거 |
|---|---|---:|---|
| 첫인사(일진·절기) · 기본 리딩 · 택일 · 궁합 점수/보완 리포트 · 소름 엔진 · 즉시요약 · 생활처방 | **없음 (룰)** | 0원 | 3층 파이프라인. 무료 존 전체가 API 비용 0 |
| 오늘 운세 한 줄 코멘트 (선택) | Haiku 4.5 | ~5원 | 짧고 가벼움. 룰만으로도 충분하면 생략 가능 |
| 토픽 심화 (연애·재물·직업·건강·올해, 1,000~2,500자) | **Haiku 4.5** | ~20–30원 | 판단은 JudgmentPack이 제공, AI는 번역·문장화. 기존 A/B 인프라(`MODEL_ALIASES`)로 품질 미달 토픽만 Sonnet 승격 |
| 후속 질문 챗 | Haiku 4.5 (무료·토픽) / Sonnet 5 (유료 리포트의 후속) | ~10–50원 | 맥락 짧음. 유료 고객 후속만 상급 모델 |
| 고민상담 (질문+선택지 비교) | **Sonnet 5** | ~200–300원 | 선택지 비교·조건 판단이 유료 가치의 핵심 — 문장력·추론 필요 |

| Evidence Gate 재생성 | 1차 생성과 동일 모델 | — | 기존 규칙 유지 (스트리밍, 버퍼링 회귀 금지) |

이미 적용돼 있음(`cache_control: ephemeral`) — 근거 데이터 블록까지 캐시 확장은 P1에서 검토.

추가 비용 레버: Sonnet 5 한시 할인($2/$10)이 2026-08-31 종료 → 9월부터 리포트 원가 1.5배 감안.
비실시간 배치 성격 작업(품질 골든 샘플 생성 등)은 Batch API 50% 할인 활용 가능.

## 7. 유입 — 정확도 입소문 루프 (광고는 나중)

트리거는 "소름 모먼트": **시스템이 먼저 과거를 맞히고 사용자가 확인**하는 순간.

1. **소름 엔진**: 계산 직후 과거 대운·세운에서 신호가 가장 강한 시기 2~3개만 골라 먼저 서술
   ("2023년 무렵, 일·거처에 큰 변화의 흐름 — 맞나요?"). 확신 없는 해는 말하지 않는다
   (빗나감 1개가 적중 3개를 지움). 기존 pastValidation(사용자 입력→채점)의 방향을 뒤집은 것.
2. 맞음/아님 응답 → caseValidation 엔진에 사례 축적 → 실측 적중 통계가 다시 신뢰 소재 (선순환).
3. 적중 순간 **공유 카드 1장** 제안(shareImage 재활용: "과거 흐름 3개 중 3개 적중").
4. 신뢰 배지 표면화: "출생시간 분 단위 보정(진태양시·서머타임)", "계산 근거 전부 공개",
   "4대 고전 교차 검증" — 기능은 전부 있음, 보여주기만 하면 됨.
   (선택) 명사도식 프레이밍: 4대 고전을 "네 관점의 교차 검증" 서사로 — 우리는 실제로 계산하므로 거짓 없음.
5. **전제 — 무료가 알차야 한다**: 소름이 무료 구간에서 터지므로 기본 리딩은 "맛보기"가 아니라
   완결된 한 상 (§8).

## 8. 리딩 구성

### 무료 기본 리딩 (룰 렌더, 7블록 — 6개는 기존 자산 재배치)
1. 소름 검증 (신규 — §7) 2. 원국 스냅샷+일간 한 줄 3. 내 사용 설명서 4. 분야별 현재 신호
(일·돈·관계·컨디션, eventEngine 재사용) 5. 올해 흐름 미니 캘린더 (monthFlowNarrative)
6. 생활 처방 7. 각 블록 끝 "이 부분 깊게 보기" = 유료 진입점

### 유료
- 토픽 심화: 한 줄 결론 → 지금 흐름 → 조심할 것 → 시기 → 행동 (토픽별 3~5섹션, 기존 구체성 원칙 유지)
- 평생사주 12섹션 / selfDeep 12블록 / personDeep 16항목: 이미 정의됨. 간판 작업(B)은 구성 추가가
  아니라 **문장 밀도·PDF 품질** 끌어올리기.
- 품질 축 추가: 검증 항목에 "차갑게 읽히지 않는가"(정서 축) — 헬로우봇 유료 사용자 분석 근거.

명사도가 6만 원을 받는 시장이므로 9,900은 보수적 시작점 — 품질(PDF) 검증 후 상위 SKU 여지.
실결제 연동 전, 카드에 가격 표시 + 클릭/완독 데이터로 수요 검증(기존 next_steps 결론 유지).

## 11. 실행 — 3덩어리

| 덩어리 | 내용 | 성공 기준 |
|---|---|---|
| **A. 속도** | P0 룰 렌더러(기본 리딩 조립) → 토픽 AI 심화 파이프라인(topic 템플릿+Haiku) → 말풍선/도착순 공개 UI | 기본 3초 / 토픽 30초 |
| **B. 간판 퀄리티** | 평생사주·상대 해부 문장 밀도 + PDF 품질 + 리포트 진행 화면 | "돈 낼 만한" 육안 검증 |
| **C. 소름 루프** | 소름 엔진 + 공유 카드 + 신뢰 배지 + 사이드바(프로필 전환 포함) | 무료 리딩 → 공유까지 동선 완성 |

토픽 5종 템플릿 확장·카드 홈 전면 개편·가격 노출은 A~C 뒤. 순서: A → (B ∥ C).

## 12. 불변식

- 계산 엔진(saju.ts·eventEngine)·궁합 점수·검증 게이트 로직은 재기획으로 변경하지 않는다.
- Evidence Gate는 스트리밍 1차 + 실패 시에만 재생성 (버퍼링 패턴 복귀 금지, 2026-07-07).

- 원국 스냅샷 즉시 노출 유지 (CLAUDE.md 히스토리 노트 — 재접힘 금지).
- 짧아진 토픽도 뭉뚱그리지 않는다 — 구체성 원칙(2026-07-07) 유지.
