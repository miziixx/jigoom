# 앞으로 해야 할 일

작성일: 2026-07-04

## 1. 먼저 해야 할 검증

### 실사용 테스트 5개

아래 케이스를 직접 돌려보고 결과를 저장한다.

1. 전체 사주 풀이
2. 연애 질문
3. 직업/금전 질문
4. 타로 질문
5. 궁합
   - 연인 관계
   - 가족 관계
   - 사장·직원 또는 동료 관계
   - 점수가 낮거나 부딪힘 신호가 많은 케이스

각 테스트에서 확인할 것:

- 질문에 바로 답하는가
- 결과가 중간에 끊기지 않는가
- 너무 오래 걸리지 않는가
- 어려운 용어가 본문에 노출되지 않는가
- 전문가 근거 보기에는 근거가 남아 있는가
- PDF/마크다운/이미지 저장 결과가 상품처럼 보이는가
- 돈을 낼 만큼 정보량이 충분한가
- 궁합의 `관계 보완 리포트`가 실제로 도움이 되는가
- 궁합에서 `나`, `상대`, `둘이 같이` 조언이 잘 구분되는가
- 궁합의 대화 예시가 너무 일반론처럼 보이지 않는가

### 상담형 사주 리포트 테스트

AI 사주가 뭉뚱그려진다는 불만을 줄이기 위해 새로 넣은 상담형 입력을 실제 질문으로 확인한다.

테스트 질문:

1. "회사를 계속 다닐지 퇴사할지 고민돼요."
   - 선택지: A 유지 / B 퇴사 후 프리랜서 준비 / C 이직 준비하며 병행
   - 확인: 선택지 비교가 실제로 다르게 나오나
2. "요즘 인간관계에서 계속 기운이 빠져요."
   - 최근 상황: 가까운 사람과 연락·약속·돈 문제 반복
   - 확인: 반복 패턴과 듣기 싫어도 봐야 할 부분이 구체적인가
3. "연애를 시작해도 되는지, 아직 기다려야 하는지 궁금해요."
   - 두려운 결과: 또 비슷한 사람에게 끌릴까 봐 걱정
   - 확인: 조심할 상대 유형과 행동 기준이 뻔하지 않은가

확인할 것:

- `질문 중심 핵심`이 질문에 바로 답하는가
- `[선택지 비교]`가 단순 장단점이 아니라 조건·위험·움직일 신호를 주는가
- `[듣기 싫어도 봐야 할 부분]`이 공포 표현 없이 날카로운가
- "신중하세요", "무리하지 마세요" 같은 일반론이 남아 있지 않은가
- 오늘/이번 주/이번 달 행동 계획이 실제 행동으로 이어지는가
- 상담형 입력이 없을 때 기존 전체 사주 리포트가 과하게 복잡해지지 않는가

### 상품 구성 원칙

- PDF 저장은 별도 판매보다 유료 리포트에 포함하는 편이 좋다.
- 상반기/하반기는 별도 상품보다 `올해 운세 리포트` 안에 포함하는 편이 좋다.
- 처음부터 120페이지 PDF를 목표로 하지 않는다.
- 먼저 20~40페이지급으로 읽을 가치 있는 리포트를 만든다.
- 나중에 충분히 검증되면 60~80페이지급 프리미엄 리포트로 확장한다.

## 3. 가격 검증

현재 판단:

- 지금 상태 그대로 9,900원짜리 완성형 리포트로 팔기엔 PDF 품질 검증이 더 필요하다.
- 4,900원~7,900원짜리 정밀 리딩/베타 상품으로는 가능성이 있다.
- 전체 사주 리포트는 `정식가 9,900원 / 베타가 7,900원` 방식이 적당하다.

해야 할 일:

- 경쟁 서비스 가격 조사
- 질문 1개 가격 조사
- PDF 리포트 가격 조사
- 사람 상담 가격과 AI 리포트 가격 구분
- 친구 5명에게 가격 감각 물어보기

질문 예시:

- 이 결과에 4,900원을 낼 수 있는가?
- 전체 사주 리포트에 7,900원을 낼 수 있는가?
- PDF로 저장된다면 가격 체감이 달라지는가?
- 어떤 상품명이 가장 끌리는가?
- 너무 비싸다고 느끼는 지점은 어디인가?

## 4. PDF 리포트 품질 강화

유료화 전에 PDF는 반드시 상품처럼 보여야 한다.

필요한 구성:

- 표지
- 이름/출생 정보
- 사주 원국 표
- 오행 그래프
- 음양 그래프
- 개인 생활 처방
  - 고유 색
  - 고유 숫자
  - 맞는 방향
  - 장소/지역/자연 키워드
  - 운동/회복 루틴
  - 건강 체크 포인트
  - 바로 실행 3개
- 신살/십성/대운/세운 근거
- 쉬운 풀이 본문
- 월별 캘린더
- 오늘/이번 주/이번 달 행동
- 전문가 근거 보기
- 주의 안내

검토할 것:

- PDF 페이지가 너무 빽빽하지 않은가
- 문단이 길어서 읽기 힘들지 않은가
- 그래프/표가 모바일 캡처처럼 보이지 않고 리포트처럼 보이는가
- 저장 파일명이 알아보기 쉬운가

## 5. 홈 화면과 메뉴 정리

현재 기능이 많아졌기 때문에 사용자가 처음 들어왔을 때 길을 잡아줘야 한다.

홈에서 추천할 진입:

- 내 전체 흐름이 궁금하면: 전체 사주 리포트
- 올해가 궁금하면: 올해 운세 리포트
- 관계가 궁금하면: 정밀 궁합
- 지금 질문 하나가 급하면: 사주+타로 질문 리딩
- 오늘만 가볍게 보면: 오늘 운세

해야 할 일:

- 홈 화면 상품 카드 정리
- 무료/유료 구분 표시
- 베타 가격 표시 여부 결정
- “처음이라면 이걸 보세요” 안내 추가

최근 1차 반영:

- 홈 화면을 `내 사주 정밀 리포트`, `지금 고민 상담`, `궁합·관계 분석` 3개 중심으로 개편했다.
- 다음 단계에서는 이 3개를 무료/유료 상품 카드와 연결할지, 아직 메뉴 진입 카드로 둘지 결정해야 한다.

주의:

- **성능 주의 (2026-07-07 수정됨, 회귀 금지):** `api/reading.ts`의 Evidence Gate는 반드시 `anthropic.messages.stream()`으로 1차 생성을 실제 스트리밍하고, 로컬 검증(`validateOutputAgainstJudgmentPack`, API 호출 없음) 실패 시에만 `rewriteAfterFailedGate`로 2차 생성을 해야 한다. 과거 한 번 `streamBufferedJudgmentGatedReply`(non-streaming으로 전체 응답을 만든 뒤 한 번에 전송)로 구현되어 모든 새 리딩이 330초 이상 걸리는 회귀가 있었다(진행 상황이 전혀 안 보였음). Evidence Gate를 다시 손댈 때 이 버퍼링 패턴으로 되돌리지 말 것.
