# 앞으로 해야 할 일

작성일: 2026-07-04

## 1. 먼저 해야 할 검증

### 실사용 테스트 5개

아래 케이스를 직접 돌려보고 결과를 저장한다.

1. 전체 사주 풀이
2. 연애 질문
3. 직업/금전 질문
4. 타로 질문
5. 궁합
   - 연인 관계
   - 가족 관계
   - 사장·직원 또는 동료 관계

각 테스트에서 확인할 것:

- 질문에 바로 답하는가
- 결과가 중간에 끊기지 않는가
- 너무 오래 걸리지 않는가
- 어려운 용어가 본문에 노출되지 않는가
- 전문가 근거 보기에는 근거가 남아 있는가
- PDF/마크다운/이미지 저장 결과가 상품처럼 보이는가
- 돈을 낼 만큼 정보량이 충분한가

## 2. 상품 구성 정리

현재 구상 중인 상품:

- 월별 리포트
- 전체 사주 리포트
- 올해 운세 리포트
- 상반기 리포트
- 하반기 리포트
- 정밀 궁합 리포트
- 사주+타로 질문 리딩
- PDF 파일 저장
- 질문 5개 충전

추천 정리:

### 출시 초기 상품 3개

| 상품 | 포함 내용 | 베타 가격 후보 |
|---|---|---:|
| 올해 운세 리포트 | 올해 핵심 주제, 상반기/하반기, 1월~12월, 실행 캘린더, PDF 저장 | 7,900원 |
| 전체 사주 리포트 | 원국, 오행, 십성, 신살, 성격, 직업, 재물, 연애, 건강, 대운, 보완법, PDF 저장 | 7,900~9,900원 |
| 정밀 궁합 리포트 | 관계 유형별 궁합, 반복 패턴, 개선 방향, 시기 흐름, 전문가 근거, PDF 저장 | 6,900~7,900원 |

### 이후 추가 상품

| 상품 | 방향 | 가격 후보 |
|---|---|---:|
| 월별 리포트 | 특정 월 집중 분석 | 4,900원 |
| 사주+타로 질문 리딩 | 질문 하나를 사주 장기 흐름 + 타로 현재 흐름으로 분석 | 5,900~8,900원 |
| 질문 5개 충전 | 이미 산 리포트에 이어 묻기 | 2,900~3,900원 |
| 프리미엄 종합 PDF | 전체 사주 + 올해 운세 + 궁합 + 타로 질문 포함 | 14,900~29,000원 |

### 상품 구성 원칙

- PDF 저장은 별도 판매보다 유료 리포트에 포함하는 편이 좋다.
- 상반기/하반기는 별도 상품보다 `올해 운세 리포트` 안에 포함하는 편이 좋다.
- 처음부터 120페이지 PDF를 목표로 하지 않는다.
- 먼저 20~40페이지급으로 읽을 가치 있는 리포트를 만든다.
- 나중에 충분히 검증되면 60~80페이지급 프리미엄 리포트로 확장한다.

## 3. 가격 검증

현재 판단:

- 지금 상태 그대로 9,900원짜리 완성형 리포트로 팔기엔 PDF 품질 검증이 더 필요하다.
- 4,900원~7,900원짜리 정밀 리딩/베타 상품으로는 가능성이 있다.
- 전체 사주 리포트는 `정식가 9,900원 / 베타가 7,900원` 방식이 적당하다.

해야 할 일:

- 경쟁 서비스 가격 조사
- 질문 1개 가격 조사
- PDF 리포트 가격 조사
- 사람 상담 가격과 AI 리포트 가격 구분
- 친구 5명에게 가격 감각 물어보기

질문 예시:

- 이 결과에 4,900원을 낼 수 있는가?
- 전체 사주 리포트에 7,900원을 낼 수 있는가?
- PDF로 저장된다면 가격 체감이 달라지는가?
- 어떤 상품명이 가장 끌리는가?
- 너무 비싸다고 느끼는 지점은 어디인가?

## 4. PDF 리포트 품질 강화

유료화 전에 PDF는 반드시 상품처럼 보여야 한다.

필요한 구성:

- 표지
- 이름/출생 정보
- 사주 원국 표
- 오행 그래프
- 음양 그래프
- 신살/십성/대운/세운 근거
- 쉬운 풀이 본문
- 월별 캘린더
- 오늘/이번 주/이번 달 행동
- 전문가 근거 보기
- 주의 안내

검토할 것:

- PDF 페이지가 너무 빽빽하지 않은가
- 문단이 길어서 읽기 힘들지 않은가
- 그래프/표가 모바일 캡처처럼 보이지 않고 리포트처럼 보이는가
- 저장 파일명이 알아보기 쉬운가

## 5. 홈 화면과 메뉴 정리

현재 기능이 많아졌기 때문에 사용자가 처음 들어왔을 때 길을 잡아줘야 한다.

홈에서 추천할 진입:

- 내 전체 흐름이 궁금하면: 전체 사주 리포트
- 올해가 궁금하면: 올해 운세 리포트
- 관계가 궁금하면: 정밀 궁합
- 지금 질문 하나가 급하면: 사주+타로 질문 리딩
- 오늘만 가볍게 보면: 오늘 운세

해야 할 일:

- 홈 화면 상품 카드 정리
- 무료/유료 구분 표시
- 베타 가격 표시 여부 결정
- “처음이라면 이걸 보세요” 안내 추가

## 6. 결제 전 정책 정리

결제 기능을 넣기 전에 아래 정책이 필요하다.

- 결제 후 생성 실패 시 재생성 가능 여부
- 결제 후 API 오류 발생 시 처리 방식
- 환불 기준
- 결과 저장 기간
- 개인정보 보관 여부
- 사용자가 입력한 생년월일 처리 방식
- AI 결과가 오락/자기이해 목적이라는 안내

추천:

- 결제 후 생성 실패 시 1회 재생성 제공
- 같은 리포트는 브라우저에만 저장
- 서버에 생년월일 원본 저장하지 않기
- 구매 리포트 PDF는 사용자가 직접 다운로드
- 고위험 결정은 전문가 상담 권고

## 9. 당장 하지 않아도 되는 것

- 월구독
- 120페이지 PDF
- 너무 많은 상품 동시 출시
- 모든 메뉴 유료화
- 서버 저장형 계정 시스템
- 복잡한 멤버십 등급

## 10. 현재 가장 중요한 판단

지금 앱은 기능을 더 늘리는 단계보다, 아래를 확인하는 단계다.

- 결과가 실제로 돈 낼 만큼 좋은가
- PDF가 상품처럼 보이는가
- 사용자가 어떤 상품을 가장 사고 싶어 하는가
- 가격 저항이 어디서 생기는가
- 무료 맛보기와 유료 리포트의 차이가 분명한가
