# 점성술 해석 지식베이스 검수 덤프 (엔진 업그레이드 A-1)

작성일: 2026-07-10 · 소스: `src/lib/astrologyInterpretation.ts` (현대+고전+베딕 통용 표준 상징, **참고용**)
용도: 점성술 전문가 최종 검수용 대조표 (V-1 검수 패킷 계열). 각 gloss가 표준 독법과 어긋나지 않는지 확인.

## A-1 범위·설계

`astrology_upgrade_plan.md`의 **Phase A만** 이 트랙에 편입(엔진 심화 C·D는 그 문서 일정 유지). Phase A의
"전체 프로파일 evidence 전달 + 구조화된 해석 KB"는 봇 경로(`bot/astrologyEvidence.ts`
→ `buildAstrologyEvidenceText`)에서 이미 전체 프로파일(현대·고전·베딕)+각도+트랜짓+해석 힌트를 통째로
넘기도록 구현돼 있다. A-1에서 추가한 것:

1. **고전 품위 인라인 결합** — `placementHint`가 뚜렷한 품위(도미사일/엑잘테이션/디트리먼트/폴)를 그 행성의
   배치 힌트에 바로 붙인다. 예: `토성: … 1하우스 영역에서 [도미사일: 제 집에 있음 — 편하게 제 힘으로 씀]`.
   (별도 `dignities` 목록은 그대로 유지 — 하위호환.)
2. **KB↔엔진 교차 검증 audit** — `NAKSHATRA_GLOSS` 키가 엔진 `NAKSHATRAS` 27개와 정확히 일치, `HOUSE_THEME`
   1~12 완비, `DIGNITY_GLOSS` 5상태 완비, 계산된 프로파일의 모든 행성·포인트에 `PLANET_ROLE` 존재를 자동 검증.
3. 이 검수 덤프(§6 요건).

**독법 원칙(합성):** 행성×별자리 120셀을 통째로 적지 않고 `행성=무엇(기능)` × `별자리=어떻게(방식)` ×
`하우스=어디(영역)` × `품위=얼마나 편히`로 합성한다(프로 표준 독법). 점수·계산에는 관여하지 않는다.

## 검수 컬럼

- 확신도: `표준`(교재 공통) / `이견있음`(유파 갈림) / `확인`(전문가 승인). 대부분 표준.

### 행성·포인트 역할 (PLANET_ROLE) — 기능 "무엇"

| 행성/포인트 | 기능 gloss |

| 태양 | 삶의 방향과 핵심 자아 |
| 달 | 감정 습관과 안정 욕구 |
| 수성 | 생각·소통·배우는 방식 |

| 화성 | 욕망·추진력·화내는 방식 |
| 목성 | 확장·기회·믿는 것(과하면 과잉) |
| 토성 | 책임·한계·성숙의 과제(두려움) |
| 천왕성 | 독립·변화·틀을 깨는 지점 |
| 해왕성 | 이상·상상·경계가 흐려지는 지점 |

| 라후 | 이생에서 끌리고 과욕하는 방향 |
| 케투 | 이미 익숙해 내려놓는 방향 |

사수자리 크게/낙관/자유 · 염소자리 현실/책임/꾸준 · 물병자리 독립/개성/거리 · 물고기자리 감성/경계없음/흐름.

### 각도 (ASPECT_GLOSS)

## 안전·범위 주석

- 시간 미상이면 상승궁·하우스·앵글·트랜짓 하우스 힌트를 만들지 않는다(없는 배치 지어내기 방지, 테스트로 잠금).
- 세 전통을 따로 읊지 말고 겹치는 주제부터 엮으라는 `integrationNote`가 항상 동봉된다. 엇갈리면 "전통마다 결이 다르다"고 밝힘.
- 공포·단정·의료/법률/투자 결론 금지(프로젝트 공통). gloss는 표준 상징 힌트일 뿐 예언이 아니다.
- **점수·계산 불변**(설명 텍스트 전용). 완결성은 `src/lib/astrologyInterpretation.test.ts`가 엔진과 교차 검증.
- 미편입(그 문서로 복귀): 외행성 앵글·마이너 각·아스펙트 패턴(Phase C), 진짜 트랜짓·리턴·프로그레션(Phase D),
