# 자미두수(紫微斗數) 계산 검증표

작성일: 2026-07-08
상태: Phase 0 — 엔진 도입·검증

## 목적

자미두수 원식(명궁·12궁·14주성·사화·오행국) 계산이 정확한지, 그리고 라이브러리(iztro) 버전
변화나 래퍼 매핑 실수로 값이 틀어지지 않는지 검증한다. 이 앱의 규칙상 **계산은 정확·결정론,
해석만 LLM**이므로, 자미두수를 사주와 교차검증에 쓰기 전에 원식 계산부터 신뢰할 수 있어야 한다.

## 계산 엔진

- 라이브러리: `iztro` (성숙한 자미두수 전용 TS 라이브러리). 직접 배치표를 만들지 않는다.
- 래퍼: `src/lib/ziwei.ts` — `computeZiweiChart(birthInfo)`가 iztro 출력을 `ZiweiChart`로 정규화.
- 입력 매핑:
  - 시진 인덱스 = `Math.floor((hour + 1) / 2)` (0=자시, 4=진시, 12=야자시).
  - 양력 → `astro.bySolar`, 음력 → `astro.byLunar(…, isLeapMonth, …)`.
  - 성별: male→'男', female→'女'. 언어: 'ko-KR'.
  - 출생 시간 미상(hour=null) → **null 반환**(명궁을 잡을 수 없어 차트가 무의미).

## 골든 회귀 케이스 (src/lib/ziwei.test.ts)

| 생년월일시(양력) | 성별 | 명궁 지지 | 오행국 |
|---|---|---|---|
| 1990-12-23 08:00 | 여 | 신(申) | 수이국(水二局) |
| 1988-05-02 14:30 | 남 | (명궁 플래그=지지 일치) | 목삼국(木三局) |

- 이 값들은 iztro 2.5.8 출력을 고정한 것이다. 버전 업/매핑 회귀를 잡는 가드.
- 12궁 이름이 모두 정식 명칭(명궁·형제·부처·자녀·재백·질액·천이·노복·관록·전택·복덕·부모)인지,
  명궁 플래그와 명궁 지지가 일치하는지, 사화(록·권·과·기)가 보존되는지 함께 검증.

## 외부 대조 (Phase 2 배선 전 권장)

교차검증 레이어를 사용자에게 노출하기 전에, 위 케이스를 **외부 자미두수 계산기 1곳 이상**과
대조해 명궁·오행국·주요 주성 배치가 일치하는지 스팟 체크한다. iztro는 널리 쓰이는 신뢰 엔진이지만,
정확도가 사용자 신뢰의 핵심이므로 배선 전 한 번 더 눈으로 확인한다.

## 주의점 (해석 단계에서 지킬 것)

- **시간 미상**: 명궁·12궁 전체가 흔들리므로 교차검증을 끄거나 "참고 낮음"으로 표시.
- **사주팔자만 입력**: 생년월일 원본이 없어 계산 불가 → 교차검증 생략(사주만).
- 유파에 따라 별 배치·사화 관법이 갈릴 수 있으므로 단정하지 말고 경향으로.
