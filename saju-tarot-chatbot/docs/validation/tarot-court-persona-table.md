# 타로 코트(궁정) 카드 페르소나 검수 덤프 (엔진 업그레이드 T-1)

작성일: 2026-07-10 · 소스: `src/data/tarotCourtPersona.ts` (라이더-웨이트 전통 입문서 통설 기준, **참고용**)
용도: 타로 전문가 최종 검수용 대조표 (V-1 검수 패킷 계열). 각 페르소나가 유파 통설과 어긋나지 않는지,
표현이 과하거나 사람을 규정짓지 않는지 확인. **점수·계산에는 관여하지 않으며**, 프롬프트 근거 텍스트
(`describeCourtPersona`)와 계산근거 존 UI에만 붙는다.

코트 16장 = 4슈트(완드·컵·소드·펜타클) × 4계급(Page·Knight·Queen·King). 완결성은
`src/data/tarotCourtPersona.test.ts`가 "KB = 덱 코트 카드 16장 집합"을 자동 검증(허수·누락 0) +
서술 안전성(공포·단정 금지, Page=시작/King=완성 성숙 축)을 잠근다.

## 해석 축 (두 방향)

- **계급 = 성숙 단계**: Page(배움·시작·미숙) → Knight(행동·추진·극단) → Queen(내면 성숙·수용·돌봄)
  → King(외적 통제·권위·완성).
- **슈트 = 영역**: 완드(불·열정·행동), 컵(물·감정·관계), 소드(공기·사고·언어), 펜타클(흙·현실·안정).

## 검수 컬럼

## 안전·범위 주석

- 모든 페르소나는 사람을 규정짓지 않고 그 카드가 **가리키는 태도**를 서술한다("~한 편/~쉬움" 톤).
- 공포·단정 표현(반드시·절대·질병·이혼 등) 금지 — audit 테스트가 잠금.
- 프롬프트에서는 코트 카드일 때만 `formatTarotCards`가 인물상·성숙 단계·관계 모습을 붙이고, 역방향이면
  왜곡상을 추가한다. 표면 리딩 문장은 여전히 쉬운 말로 쓰되, 이 근거를 인물 묘사에 활용한다.
- 점수·계산 불변(설명 텍스트 전용).
