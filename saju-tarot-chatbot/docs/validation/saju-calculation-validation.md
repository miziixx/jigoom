# 사주 계산 정확도 검증표

작성일: 2026-07-04

목적: 앱의 사주 계산 결과가 기준 만세력과 일치하는지 확인한다.

현재 상태: 1차 자동 회귀 테스트를 추가했다.

- 자동 테스트 파일: `src/lib/sajuCalculationValidation.test.ts`
- 외부 대조표: `docs/validation/external-manse-comparison.md`
- 검증 고정일: `2026-07-03T03:00:00Z` (KST 2026-07-03 12:00)
- 역할: 계산 로직 수정 중 연주·월주·일주·시주, 오행, 음양, 대운/세운/월운/일진이 의도치 않게 바뀌는지 감지한다.
- 한계: 아래 자동 기준값은 앱 계산 엔진 기준 회귀 테스트다. 최종 정확도 인증을 위해서는 별도 만세력 2~3곳과 대조해야 한다.

검증 대상:

- 연주
- 월주
- 일주
- 시주
- 일간
- 오행 분포
- 음양 분포
- 십성
- 통근(通根): 천간이 지지 지장간에 뿌리를 두는지 (정기/중기/여기 강도)
- 투출(投出): 월지 지장간이 천간에 드러났는지
- 격국 성패(간이): 월지 정기 투출 여부·월지 충 여부로 성격/파격/불명확
- 용신 체계: 억부(기존) + 조후(겨울생→화, 여름생→수) + 통관(대립 오행 잇기)
- 대운·세운 중첩: 대운↔세운 직접 합충 + 각각 용신/기신 방향 → 좋은 흐름 겹침/부담 겹침/엇갈림/조용함
- 대운 시작 나이
- 현재 대운
- 세운
- 월운
- 음력/윤달 변환
- 23시~24시 자시 처리
- 출생지/진태양시 보정

주의(통근·투출·용신 확장, 2026-07 추가):

- 통근/투출/조후·통관 용신/격국 성패는 기존 계산값(연월일시주·오행·십성·대운 등)을 바꾸지 않는
  additive 필드다. 회귀 테스트(`sajuCalculationValidation.test.ts`)의 고정값은 유지된다.
- 통근은 "같은 오행" 기준(음양 무관). 지장간 배열은 여기·중기·정기 순(마지막이 정기).
- 조후는 겨울(해자축월)→화, 여름(사오미월)→수만 간이 판정하고, 환절기는 null.
- 통관은 최강 두 오행이 각 2 이상이고 상극일 때만, 사이를 잇는 오행을 제시.
- 격국 성패는 간이 규칙(투출·충)이며 전문 격국론의 상신·기반 판단까지는 아니다.

주의(월률분야·격국 투출·한난 조후, 2026-07 추가):

- 월률분야(사령)는 `lunar.getPrevJie()` 절입 경과일수 기준으로 여기·중기·정기 사령을 판정하는 신규 additive 필드(`SajuChart.monthCommand`)다. 연월일시주·오행·십성·대운 고정값은 불변.
- 격국은 이제 정기 고정이 아니라 ① 정기 투출 ② 정기 불투 시 투출한 지장간(중기>여기) ③ 투출 전무 시 사령 순으로 격을 잡는다(`gyeokguk.basisStem`/`basisKind`). `basis` 문자열에는 "월지"가 유지된다.
- 조후는 계절 온도(MONTH_TEMP)+일간 온도(GAN_TEMP) 한난 지수 기반 간이다. 을木 오월→수, 임水 자월→화 같은 기존 잠금값은 유지. 일간×월지 궁통보감 정밀표는 후속 과제.
- 회귀 스냅샷 유지 확인: `sajuCalculationValidation.test.ts`, `sajuFeatures.test.ts` 무변경 통과, 신규 `sajuPrecision.test.ts`로 사령·격국·조후 검증.
