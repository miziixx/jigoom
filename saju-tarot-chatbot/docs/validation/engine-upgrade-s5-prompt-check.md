작성일: 2026-07-10 · 대상: S-1~S-4에서 추가한 사주 심화 근거가 프롬프트에 어떻게 실리는지 정적 검증
절차: `reading-quality-validation.md`의 "AI 답변 근거 반영 / 쉬운 언어 / 안전성" 항목 중 **프롬프트 단계에서
자동 확인 가능한 부분**을 렌더링·테스트로 고정. LLM 생성물 육안 검증은 API 키 있는 환경 백로그로 이월.

## 확인한 것 (프롬프트 렌더링, 원국: 남 1972-01-30 06:00 — 파격+조후 미충족 케이스)

### 기본 리딩 (JudgmentPack Evidence Gate 경로)
- S-2 심화 판단 코드가 실제로 프롬프트 근거에 등장: `STRUCTURE_BROKEN_CAUTION`(탐재괴인 파격 → career),
  `CLIMATE_BALANCE_NEEDED`(궁통보감 1순위 화 미충족 → health).
- 근거 줄에 심화 근거 문자열 노출: `격국 심화(자평진전): 정인격 파격 / 상신 관성(화) 미비 / 파격 요인
  탐재괴인`, `조후(궁통보감): 우선 천간 병→정→갑 / 1순위 화 미충족`.
- GATE_ROLE 프레이밍("judgments 결론만 번역, 새 결론·금지표현·근거없는 단정 금지")은 그대로 유지 →
  심화 근거를 더해도 안전 게이트가 약해지지 않음.

### 고급 리딩 (raw evidence + Content Gate 경로)
- S-4 대운 타임라인: `대운 흐름 (대운 역행): … [십성 …, 보완/부담 방향, 원국과 대운 …충·합]` +
  "보완 방향 대운=힘이 실리는 10년 / 부담 방향=지키고 다지는 10년 / 원국과 충=자리·환경이 바뀌기 쉬운
  구간" 해석 안내(사주 용어·공포 금지 명시).
- S-3 세운 상문·조객: 세운 타임라인 태그에 `상문살`·`조객살` 표시 + "주변 경조사가 늘거나 기운이
  가라앉기 쉬운 참고 시기로만 부드럽게 옮겨라(년지 기준·참고용). 초상·죽음·불행 같은 공포 단정 절대 금지".
