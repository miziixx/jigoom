# 궁통보감 조후용신 120셀 검수표 (JOHU_CLASSIC)

자동 생성 문서. `src/lib/saju.ts`의 `JOHU_CLASSIC`를 사람이 원전과 대조하기 쉽게 덤프한 것.
각 칸 = 그 일간·월지의 **우선순위 조후용신 천간**(1순위→). 칸 값은 모두 천간이다(辛은 申 아님).
1순위는 서락오 정리 통용본과 대조 확인함. 하위순위는 판본 차이 가능 → 전문가 최종 검수 권장.

## 검수 방법
- 자동 가드: `src/lib/johuClassicAudit.test.ts` — 120셀 완결성, 유효 천간/중복, 조후 원리(목·금·토 일간은 한여름 水·한겨울 火), 원전 스팟체크.
- 火 일간(丙丁)은 겨울에도 스스로 덥고, 水 일간(壬癸)은 여름에도 스스로 차가워 자기조절 → 반대 오행을 조후로 두지 않는 것이 정상.
- 최종 확정 전, 명리 전문가가 이 표를 원전(欄江網/造化元鑰)과 1:1 대조 권장.
