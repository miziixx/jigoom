# 궁합 고전 보완 서술 (C-2) — 검수 덤프

> 엔진 업그레이드 C-2. `computeCompatibility().classicComplement`가 **통관용신·궁통보감 조후**를
> 점수 변경 없이 서술로만 반영한다. 이 문서는 로직 요약 + 실제 샘플 출력 + V-1(전문가 검수) 대상 표시.

## 로직 요약 (새 계산·점수 변경 없음)

이미 계산된 두 필드만 읽어 **상대 원국 오행**과 대조한다:

| 축 | 소스(이미 계산됨) | 발동 조건 | 서술 |
|---|---|---|---|
| **조후 (궁통보감)** | `chart.yongshin.climaticClassic` (`JOHU_CLASSIC` 표, 일간×월지) | self의 1순위 조후 오행이 원국에 **결핍**(`satisfied === false`)인데 상대 `fiveElements[그 오행] >= 2` | "상대가 계절처럼 치우친 리듬을 채워준다" |
| **통관** | `chart.yongshin.mediating` (강하게 대립하는 두 오행을 잇는 bridge 오행) | self에 통관 bridge 오행이 필요한데 상대가 그 오행을 넉넉히(>= 2) 지님 | "상대가 부딪히는 두 기운 사이를 이어준다" |

- 양방향(A→B, B→A) 모두 검사. 둘 다 발동하면 문장을 "두 사람 다 …" 형태로 합친다.
- **점수 불변식**: 이 함수는 `classicComplement`(신규 optional 필드) + `repairReport.byPerson.together`(서술 append)
  + `expertEvidence`(근거 한 줄)만 채운다. 점수 산식(`raw = 48 + dm + branch + elements + johu + palace`)은 미접촉.
  기존 `johuComplement`(간이 조후, 점수 -4~+8)는 그대로 유지 — 그건 점수용, 이건 서술용으로 역할이 분리됨.
- **표면 용어 금지**: `headline`/`johu.plain`/`mediating.plain`/`together`에는 조후·통관·용신 등 용어를 쓰지 않고,
  오행은 `ELEMENT_PLAIN`(예: 화→"표현하고 가까워지는 힘")으로 번역. 간지·오행명·용어는 `evidence`에만.
- 보완 신호가 하나도 없으면 `classicComplement === undefined`(필드 자체를 안 채움).

## 실제 샘플 출력 (roleLabels 기본값 나/상대)

### 샘플 1 — 통관만 발동
```
headline : 부딪히기 쉬운 기운 사이를 서로 이어주는 보완이 있는 궁합이에요.
mediating: 상대는 마음속에서 두 가지 강한 기운이 부딪히기 쉬운데, 내가 그 사이를 이어주는
           '감정과 생각을 깊게 살피는 힘'을 지녀서 곁에 있으면 갈등이 순환으로 풀리기 쉬워요.
evidence : 통관 보완: 상대 통관용신 수(강한 두 기운 대립을 잇는 오행) 필요 → 나가 수 기운 보유
together : 의견이 팽팽할 때 중간에서 이어주는 사람의 역할을 서로 인정해 주면, 다툼이 오래 가지 않고 방향이 잡힙니다.
```

### 샘플 2 — 조후 + 통관 둘 다 발동
```
headline : 서로의 치우친 기운을 채워주고 부딪히는 기운 사이를 이어주는, 고전적으로도 잘 맞물리는 보완이 있는 궁합이에요.
johu     : 내가 상대에게 부족한 '표현하고 가까워지는 힘'을 넉넉히 지녀서, 계절처럼 치우치기 쉬운
           리듬을 곁에서 자연스럽게 채워주는 편이에요.
           (근거: 상대 궁통보감 조후 1순위 화(병·계) 결핍 → 내가 화 기운 넉넉히 보유)
mediating: 상대는 마음속에서 두 가지 강한 기운이 부딪히기 쉬운데, 내가 그 사이를 이어주는
           '표현하고 가까워지는 힘'을 지녀서 곁에 있으면 갈등이 순환으로 풀리기 쉬워요.
           (근거: 상대 통관용신 화 필요 → 내가 화 기운 보유)
```

### 샘플 3 — 통관만(bridge = 토)
```
headline : 부딪히기 쉬운 기운 사이를 서로 이어주는 보완이 있는 궁합이에요.
mediating: 상대는 … 그 사이를 이어주는 '생활을 안정시키는 힘'을 지녀서 …
evidence : 통관 보완: 상대 통관용신 토(강한 두 기운 대립을 잇는 오행) 필요 → 나가 토 기운 보유
```

## V-1(전문가 검수) 대상 표시

| 항목 | 확신도 | 검수 포인트 |
|---|---|---|
| 조후 결핍 판정(`climaticClassic.satisfied`) | 중 | `JOHU_CLASSIC` 표는 `johuClassicAudit.test.ts`가 완결성 잠금. 1순위 결핍→상대 보충 논리 자체는 통설이나, "상대 오행 2개 이상 = 보충"의 임계값은 통용 근사(검수 대상). |
| 통관 bridge 판정(`mediatingYongshin`) | 중하 | "가장 강한 두 오행이 상극이면 그 사이 bridge를 통관으로 본다"는 간이 규칙. 실제 통관용신은 격국·투출까지 보는 게 정석이라, 여기 서술은 **참고용**. |
| 서술 톤/번역 | 상 | 표면 용어 금지·`ELEMENT_PLAIN` 번역은 기존 컨벤션과 동일. |

- 점수에는 전혀 반영되지 않으므로(서술 전용) 오판정이 있어도 정확도 지표는 흔들리지 않는다.
- 단정 금지: 모든 문장은 "~편이에요/~쉬워요" 톤 유지, "반드시/꼭"류 없음.
