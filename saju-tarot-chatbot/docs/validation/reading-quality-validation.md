# 사주타로 리딩 품질 검증표

작성일: 2026-07-04

목적: AI 리딩이 실제 계산 근거를 잘 반영하는지, 사용자가 이해하기 쉬운지, 체감 정확도가 있는지 점검한다.

검증 대상:

- AI가 근거 없는 말을 하지 않는가
- 어려운 사주 용어를 쉬운 말로 번역하는가
- 전문 용어는 전문가 근거 영역에 보존되는가
- 사용자가 자신의 현실에 적용할 수 있는가
- 조언이 구체적인 행동으로 이어지는가
- 공포감이나 단정 표현이 없는가
- 건강/투자/결혼/퇴사 등 고위험 영역을 안전하게 다루는가
- 사용자가 "내 얘기 같다"고 느끼는가

판정 기준:

- 근거 있음: 사주 원국, 운 흐름, 타로 카드, 기존 리딩 내용에서 확인 가능
- 근거 약함: 완전히 틀리지는 않지만 근거가 간접적이거나 표현이 과함
- 근거 없음: 계산 데이터나 질문 맥락에서 확인되지 않음
