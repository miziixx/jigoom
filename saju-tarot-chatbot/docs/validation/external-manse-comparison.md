# 외부 만세력 대조표

작성일: 2026-07-04

목적: 앱의 사주 계산 결과를 외부 만세력 2~3곳과 비교해 실제 정확도를 확인한다.

중요:

- 이 문서는 내부 회귀 테스트가 아니라 외부 검증용이다.
- 앱 결과가 외부 만세력과 다를 때는 바로 오류로 단정하지 않는다.
- 먼저 입춘 기준, 자시 처리, 출생지 보정, 서머타임, 대운 시작 나이 산정법 차이를 확인한다.
- 외부 만세력 결과가 2곳 이상 일치하고 앱만 다르면 계산 로직 수정 후보로 본다.
- 우선 기준은 신한라이프 운세/사주, coldcow 운명, goodcycle 무료세계만세력으로 둔다.

## 비교할 외부 만세력

| 구분 | 이름 | URL/앱 | 설정 | 확인일 | 비고 |
|---|---|---|---|---|---|

| 만세력 B | coldcow 운명 | https://saju.coldcow.dev | 양력/음력, 성별, 시/분 입력 기준 | 2026-07-04 | 사용자 추천 기준, 자동 대조 가능 |
| 만세력 C | goodcycle 무료세계만세력 | http://www.goodcycle.com/alib/ | 야자시/절입/경도/써머타임/균시차 옵션이 있는 화면 기준, 결과의 기준시각 함께 기록 | 2026-07-04 | 사용자 추천 기준, 이미지 간지 코드를 한자 간지로 판독 |
| 만세력 D | 사주매니아 만세력 | https://sajumania.com | `YYYYMMDDHHMM`, 성별, 양/음/윤 선택 기준 | 2026-07-04 | 사용자 추천 기준, 자동 대조 가능 |

자동 확인 메모:

- 신한라이프 운세/사주는 2026-07-04 기준 자동화 환경에서 입력 본문이 iframe 내부로 비어 보여 수동 확인이 필요하다.
- coldcow 운명은 2026-07-04 기준 자동 입력 및 결과 추출이 가능했다.
- coldcow 입력 화면에서는 윤달 선택 옵션이 확인되지 않아 음력 윤달 케이스는 별도 수동 확인이 필요하다.
- goodcycle 무료세계만세력은 2026-07-04 기준 자동 입력 및 결과 추출이 가능했다.
- goodcycle은 결과의 천간/지지를 이미지 파일명으로 표시하므로 `h1=갑, h2=을 ... h10=계`, `e1=자, e2=축 ... e12=해`로 판독했다.
- 사주매니아 만세력은 2026-07-04 기준 자동 입력 및 결과 추출이 가능했다.
- 사주매니아는 음력 윤달 입력 옵션이 있어 윤달 케이스까지 자동 대조했다.
