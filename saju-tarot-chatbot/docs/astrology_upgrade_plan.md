# 점성술 프로급 업그레이드 기획안

작성일: 2026-07-08
상태: 방향 확정, 추천 순서대로 구현 중 (Phase별 main 커밋)

## 확정된 방향

- **세 전통 통합 심화**: 현대 서양 + 고전(헬레니즘) + 베딕을 균형 있게 깊이 올린다.
- **봇·웹 공용 엔진**: `src/lib/astrology.ts` 하나를 키우면 텔레그램 봇과 웹이 동시에 좋아진다.
- **곁들임**: 자연어 인식 확장(`intentDetector`) + 글쓰기 비서 모드 강화(`secretary`).

## 설계 원칙 (기존 프로젝트 규칙 계승)

1. **계산은 엔진, 해석만 LLM.** 좌표·행성 위치는 `astronomy-engine`이 결정론적으로 계산하고, Claude는 그 값만 근거로 해석한다. 없는 값 지어내기 금지.
2. **엔진 하나로 봇·웹 공용.** `src/lib/astrology.ts`가 이미 양쪽에서 쓰인다. 여기만 확장한다.
3. **계산한 건 전부 근거로 넘긴다.** 지금은 엔진이 풍부하게 계산해도 봇엔 얇은 요약만 전달된다(`buildAstrologyEvidenceText`). 이게 가장 큰 낭비이자 즉효 포인트.
4. **유파 갈리는 판정·시간 미상은 그대로 밝힌다.** 사주에서 지키는 톤을 점성술에도 적용.

## 지금 수준 (이미 계산 중)

- **현대**: 태양·달·상승궁·금성·화성 (별자리·도수·홀사인 하우스·키워드)
- **고전**: 7행성 품위(도미사일·엑잘테이션 등)·섹트(낮/밤 차트)·룰러
- **베딕**: 나크샤트라+파다·라후/케투 축·빔쇼타리 마하다샤
- **공통**: 5대 각도(합·육십분·사각·삼분·충) orb 계산 · 오늘 태양/달 트랜짓 하우스 테마

## 프로급까지의 갭

| 영역 | 지금 | 프로급에 필요한 것 |
|---|---|---|
| 행성 | 태양·달·금성·화성 중심 | 수·목·토 전면 + **외행성(천왕·해왕·명왕)**, 노드·(카이런) |
| 하우스·앵글 | 홀사인만 | **MC(중천)·IC** = 커리어 축, 플라시두스 옵션 |
| 각도 | 5대 각도만 | 마이너 각(150·30·45·135°) + **패턴(T스퀘어·그랜드트라인·요드·스텔리움)** |
| 타이밍·예측 | 오늘 태양·달 하우스 | **진짜 트랜짓·새턴 리턴·솔라 리턴**, 프로그레션 |
| 베딕 심화 | 마하다샤만 | 안타르다샤(부기) + **나밤샤(D9)** + 요가·드리쉬티 |
| 해석 근거 | 압축 JSON, 얇게 전달 | **전체 프로파일 전달 + 구조화된 해석 지식베이스** |

## 로드맵

### Phase A — 해석 근거 강화 (즉효·저비용) ← 먼저
- `buildAstrologyEvidenceText`가 전체 프로파일(고전 품위·베딕 다샤·전체 배치)을 근거로 전달하게 확장. 사주의 `buildNatalEvidence` 스타일.
- 구조화된 해석 지식베이스: 행성×별자리, 행성×하우스, 각도 의미, 품위 함의, 나크샤트라 뜻을 짧은 gloss로. 사주의 `iljuTraits`·신살풀이에 대응.
- 웹: `SajuFactsPanel`에 대응하는 `AstrologyFactsPanel`(차트 휠 시각화).

### Phase B — 자연어 인식 확장 + 글쓰기 모드 (즉효·저비용) ← 먼저
- `intentDetector`의 astrology 트리거 확대: 행성명·하우스·새턴리턴·역행·트랜짓·차트·네이탈·아스펙트·다샤·나크샤트라.
- (검토) 규칙 못 잡은 애매 문장은 가벼운 LLM 폴백 분류.
- 글쓰기 모드: 목적·독자·톤 확인 후 완성본+변형 기본 제공, "AI 티 제거" 규칙 구체화, 장르 프리셋 검토.

### Phase C — 엔진 심화 · 세 전통 (1차 본편)
- **현대**: 외행성(천왕·해왕·명왕), MC·IC 앵글, 마이너 각+아스펙트 패턴, 어플라잉/세퍼레이팅.
- **고전**: 차트 룰러 확정, 트리플리시티·텀·페이스 품위 점수화, 섹트 강조, (선택) 연간 프로펙션.
- **베딕**: 안타르다샤(부기), 나밤샤(D9), 그라하 드리쉬티, 주요 요가 근사.

### Phase D — 타이밍·예측 (2차)
- 진짜 트랜짓(현재 행성 → 원국 행성·앵글 각도).
- 새턴 리턴/주피터 리턴 + 솔라 리턴(생일 차트) 요약.
- 베딕: 현재 안타르다샤 + 사데사티. (선택) 2차 프로그레션 달.
- → 여기서부터 "정밀 점성술 리포트" 유료 상품화 가능.

## 추천 착수 순서

1. **Phase A + B** — 이미 계산된 값 다 넘기고 자연어 인식·글쓰기 손보기. 엔진 그대로도 체감 확 상승.
2. **Phase C** — 세 전통 엔진 심화.
3. **Phase D** — 타이밍·예측. 유료 상품화 시작점.

- 매 단계 `npm test` · `npm run build`.
- 봇: 실제 텔레그램 점성술 질문 5종. 웹: 점성술 패널·리포트 렌더 확인.

## 기술 플래그 (미리 확인)

- **카이런·소행성**: `astronomy-engine` 미지원 → 별도 천체력/근사 필요. 1차 제외 무방.
- **하우스 시스템**: 홀사인은 시간만 있으면 정확. 플라시두스는 고위도 경계 이슈 → 옵션.
- **출생시간 미상**: 상승궁·하우스·앵글·트랜짓 하우스 계산 불가 → 행성 별자리 중심으로만 답하고 한계 명시(기존 로직 유지).
- **팔자만 입력한 사용자**: 출생일 원본이 없어 점성술 계산 불가 → 안내 문구 필요.
