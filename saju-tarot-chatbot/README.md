# 인사이트 오라클 · 사주/타로 리딩 챗봇

"100% 적중"을 내세우지 않는다. 대신:
- **계산**: `lunar-javascript`(만세력) + 자체 전통 규칙 테이블로 사주 원국(연/월/일/시주), 오행·음양 분포, 천간·지지 십성, 지장간, 합충형파해, 신강/신약(간이 억부), 용신 후보, 대운·세운·월운을 전부 코드로 계산한다. AI는 계산하지 않는다.
- **해석**: 계산된 사실만 LLM(`claude-sonnet-5`)에 넘기고, 근거·경향·주의점을 구분해 밀도 있게 풀이하게 한다. 단정적 예언 표현은 시스템 프롬프트에서 금지하고, 전달된 목록에 없는 합충을 만들어내지 못하게 지시한다.
- **신강/신약·용신의 한계**: 위치 가중치 기반 간이 억부법이라 관법에 따라 판정이 갈릴 수 있다. 그래서 "후보"로만 전달하고 프롬프트에도 단정 금지를 명시했다.

### 시각 보정 (정밀 사주)
`correctBirthTime()`이 출생 시각을 사주 계산용 시각으로 보정한다:
- **진태양시**: 출생지(시/도) 경도와 표준시 기준 경선의 차이 × 4분 (예: 서울 -32분)
- **서머타임**: 한국 시행 기간(1948~60년, 1987~88년) 출생이면 -60분 (경계일 출생은 재확인 권장)
- **표준시 변경**: 1954-03-21~1961-08-09 출생은 당시 표준시(동경 127.5도, UTC+8:30) 기준으로 경도 보정
- **시주 경계 경고**: 보정 후 시각이 홀수시 정각 ±15분이면 "시주가 달라질 수 있음"을 사실 패널과 해석에 표시

### 운 타이밍 엔진
현재 대운·세운·월운·오늘 일진의 간지가 원국과 새로 맺는 합충형파해(삼합 완성 포함)를 계산해서 AI에 전달한다. "세운 병오가 월지 자와 자오충" 같은 타이밍 근거가 추론이 아니라 계산값이 된다.

## 스택
Vite + React + TypeScript + zustand + react-router-dom, Vercel 서버리스 함수(`api/reading.ts`)에서 Anthropic API 호출.

## 로컬 실행

```bash
npm install
cp .env.example .env   # ANTHROPIC_API_KEY 채우기
```

`api/`(서버리스 함수)까지 함께 로컬에서 띄우려면 Vercel CLI가 필요하다.

```bash
npm i -g vercel   # 최초 1회
vercel dev
```

프론트엔드만 빠르게 볼 때는 `npm run dev`로도 되지만, 이 경우 `/api/reading` 호출은 실패한다(서버리스 함수가 뜨지 않음).

## 빌드

```bash
npm run build
```

## 배포 (Vercel)
1. Vercel 프로젝트를 이 폴더(`saju-tarot-chatbot/`)를 루트로 연결한다.
2. 프로젝트 환경변수에 `ANTHROPIC_API_KEY`를 추가한다(클라이언트에는 절대 노출되지 않고 서버리스 함수에서만 사용됨).
3. `vercel.json`이 이미 `framework: vite`, `outputDirectory: dist`로 설정되어 있어 별도 설정 없이 배포된다.

## 현재 범위 (MVP 1~3단계)
- 사주: 입력(양/음력, 시간 모름), 원국 계산, 오행/십성, **대운·세운·월운**(성별 따라 순/역행, 입춘·절기 기준)
- 리딩 종류: 사주 / 타로 / 통합 / **오늘의 흐름**(일진 중심) / **월간·연간 운 흐름**(올해 12개월 월운을 절기 기준으로 전부 계산해 구간별 리듬으로 해석)
- 해석 포커스 선택: 전반 / 직업·돈 / 연애·관계 / 건강·컨디션 / **멘탈·감정** / **선택·시기** (포커스별 필수 항목을 프롬프트로 강제)
- **개인화 질문**: 현재 상황 단계 / 답변 톤(현실적·따뜻·냉정·상세) / 해석 깊이(가벼운·기본·고급·전문가) / 출생시간 정확도 → 오차 가능성이 있으면 시주 의존 해석의 신뢰도를 낮춰 명시
- **반대 근거 + 신뢰도 계층화**: 모든 리딩에 "반대 근거" 섹션을 강제하고, 신뢰도(높음/중간/낮음)를 근거 일관성 기준으로 판정. 근거 3개 이상이 겹칠 때만 강한 어조 허용. 핵심 주장은 관찰→의미→실제 모습→주의점→보완 5단계 문장 구조로 강제
- 타로: 1장 / 3장(과거·현재·미래) / **3장(상황·장애물·조언)** / 5장(상황·장애물·조언·주변·전개) / **5장(선택지 A/B 비교)** / **5장(한 달 흐름)** / **10장 켈틱 크로스**, 정·역방향, 자리(포지션) 의미 기반 **카드 조합 해석** + 배열별 해석 방법 지시
- **피드백 시스템**: 리딩 후 평가(잘 맞음~안 맞음)와 태그(추상적/구체적 요망/조언 좋음/설명 어려움)를 기기(localStorage)에 저장. 사용자가 체크박스로 동의한 경우에만 지난 피드백에서 뽑은 스타일 조정 힌트를 다음 리딩에 반영
- 명리 심화: 12운성, 공망(순중공망), 조후(계절) 노트가 계산되어 해석 근거로 전달됨
- 사주+타로 통합 리딩(사주=장기, 타로=단기, 충돌 시 구분), 후속 질문(챗봇형 대화), 결과 저장(localStorage)
- **즐겨찾기**: 결과 화면·기록에서 ★ 토글, 기록에서 즐겨찾기만 필터
- **리딩 비교**: 기록에서 2개 선택 → 나란히 보기 + AI 비교 분석(공통 흐름/달라진 점/지금 취할 행동)
- **PDF 저장**: 접힌 섹션을 모두 펼쳐 인쇄 다이얼로그(PDF로 저장) 실행, 인쇄 전용 밝은 테마
- **공유 이미지**: 핵심 요약과 원국/카드를 담은 1080×1350 PNG 카드 다운로드

### 프리미엄 구조
`src/lib/premium.ts`가 게이팅 뼈대다. 현재는 결제 연동 전이라 localStorage 플래그 + "체험용으로 활성화" 버튼 스텁으로 동작한다(AI 비교 분석에 적용). 실제 결제(PG/인앱)를 붙일 때는:
1. 결제 성공 콜백에서 `unlockPremium()` 호출
2. `isPremium()`을 서버 검증(구독 상태 API) 기반으로 교체
3. 유료로 돌릴 기능에 같은 패턴으로 게이트 추가 (상세 사주, 통합 리딩 등)
